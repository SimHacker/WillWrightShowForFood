title: Browse and edit
synonyms:
  - run time design time

The transferable idea in ~Hacker News archive~ is not about ~HyperTIES~:

> the much more important thing was that **it was not just a browser, but also an authoring tool, that enabled regular users to switch back and forth between browse mode and edit mode WHILE they were using it, and empowered users as authors.**

The other tools of the time — including NeXT Interface Builder — split "run time" from "design time". The web kept the split. Netscape and IE later shipped half-assed WYSIWYG that produced terrible HTML and could not be applied to any page.

~Don Hopkins~'s rule: without the ability to dynamically edit scripts at runtime, you can't hold a candle to HyperCard, because interactive scripting is an essential feature.

The lineage is now its own trail: ~HyperCard~ → ~GoodNeWS~ → ~HyperNeWS~ → ~HyperLook~. ~Arthur van Hoff~ built that. Then the Java compiler in Java, then Bongo — editing and compiling event handlers at runtime.
