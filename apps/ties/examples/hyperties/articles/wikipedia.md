Wikipedia files HyperTIES under **The Interactive Encyclopedia System**. The page is a stub, last substantial edit February 2024. It says:

TIES was a hypertext system at the University of Maryland ~HCIL~, begun by ~Ben Shneiderman~ in 1983. Early versions ran in DOS text mode, cursor keys to move. A later Sun workstation version was written by ~Don Hopkins~ on NeWS, with an authoring tool in UniPress Emacs. Cognetics Corporation sold HyperTIES as a commercial product with a small feature set and touch-screen support, aimed at kiosks. Links could be text or graphics. The mouse highlighted anchors on the way over.

That is all true and it is not enough. It does not mention ~Dan Ostroff~, ~Catherine Plaisant~, ~Rodrigo Botafogo~, or ~William Weiland~. It does not mention ~Definition previews~, the mandatory abstract, ~The blue link~, pop-out targets, or piles-of-tiles. It does not mention ~A Look Back~, which is the paper of record.

This site is that article, written in the system it describes. ~HyperTIES~ is the front page. The live 1988 demo is ~space-telescope/The Space Telescope in Orbit~.
