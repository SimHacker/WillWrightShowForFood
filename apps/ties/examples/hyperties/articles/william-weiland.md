~HyperTIES~ browser development, and specifically the index manager in C — the component that mapped an article or object name to its location in a file. That is the mechanism the synonym design rests on.

The archive keeps ~Don Hopkins~'s email to `weiland@bensun` asking for `.h` files "for the index manager so that I can include them in fmt.c". Resolution was Bill's. Formatting was Don's.
