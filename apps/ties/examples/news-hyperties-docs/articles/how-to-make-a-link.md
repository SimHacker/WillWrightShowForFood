The command syntax is: <white space>~<white space><reference>~

(Generally a space, followed by a dot, directly followed by a tilde and a space, then the text of the button terminated by another tilde.)

For example, `.~ button~` As usual the text of the button should be the ~article title~ or a ~synonym~ of an article title.

The effect of this link is a jump to the beginning of the article whose title is given between the tildes.

IN THE NEAR FUTURE:

We will go back the the use of the tildes (e.g. ~button~), which are easier to use and don't disturb the reading of the storyboard so much. We now use the `.~` command to simplify the job of the ~formatter~.

IN THE DISTANT FUTURE:

We could provide typed links by providing different link commands.
