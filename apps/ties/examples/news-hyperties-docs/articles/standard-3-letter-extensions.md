---
title: standard 3 letter extensions
synonyms:
  - standard 3 letter file extensions
definition: Describe the standard names used for all the database files.
source: doc/standexten.st0
---

Since a Hyperties database will consist of several types of component files, there will be a set of standard 3-letter extensions used to identify file types to the system.  These extensions will identify the nature of the contents of a file, its system-specificity, and a general version number, to permit some evolution of the internal file formats without "orphaning" existing databases.  For example, the initial portable storyboard files will have the extension ".st0", and a later version of the (non-portable) PS/2 display file  may be ".ps3".
