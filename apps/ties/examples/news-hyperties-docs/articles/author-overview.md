An Hyperties database is a set of articles.  The main thing to do is to write a ~storyboard~ for each article.  You are free to organize your files any way you want under a root directory (see ~examples of database organisation~). The root directory name is what is used to invoke the browser on the database.

Of course, if you include graphics in your database, you will also have to include the graphic files and ~associated files~ in your database directory to resolve the ~picture and target names~ used in the storyboards.

Today there is still no authoring tools available.  You have to do everything using your favorite text editor. While writing this documentation database, suggestions have been made about the ~needed tools for an author~.

When the database is ready (or to try it) follow the steps...

1- Build the ~. master index~. For that you have to invoke the ~make-index program~ from the ties directory (which includes all the executables).
