# Ben Shneiderman's HyperTIES archive

Static access copies generated from the restored historical archive at
https://github.com/SimHacker/Hyperties. The repository is the source of truth;
files here are build outputs copied for publication.

- `reading-room/index.html`: self-contained reading room for the recovered
  *Hypertext on Hypertext* book records and the earlier Holocaust museum
  encyclopedia. Generated by `analysis/build-reading-room.mjs`. No network
  dependencies; works standalone or in an iframe.
