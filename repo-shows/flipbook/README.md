# Flipbook — graphics department catalog

**Flipbook is our graphics department.** Timed illustrated mini-shows that play during narration — full-bleed B-roll when voice carries the story and scrolling markdown does not.

Spec: [`../../process/post-production/flipbook-shows.yml`](../../process/post-production/flipbook-shows.yml)

## Flipbook vs Pop-Up

| | **Flipbook** | **Pop-Up** (Howard) |
|---|-------------|---------------------|
| Base | Illustrated pages / diagrams | Screen recording of repo or web |
| Role | B-roll during narration | Annotations on the evidence tour |
| When | Thesis, history, mechanism | Walking the repo, hover digressions |

Both can appear in one episode: Flipbook for the Soul City namesake act; Pop-Up when Don scrolls the paper index.
