# Tom Ngo + Golan Levin — ECG & Mouther 🔺🎛️

> **Brainstorm show.** Conversation, not code.
> ([Heartbeat](../../process/brainstorm-heartbeat.md))

**[Tom Ngo](../../characters/tom-ngo/)** built **Embedded Constraint Graphics** at Interval.
**[Golan Levin](../../characters/golan-levin/)** used that editor (with Malcolm Slaney on speech)
for **[Mouther](https://www.flong.com/archive/projects/mouther/)** — speech-driven cartoon faces.

Patent [US5933150](https://patents.google.com/patent/US5933150) expired ~2016. The dream is to
sit both of them down and **talk**: how to reverse-engineer or recover the Mouther cartoons;
how a modern ECG engine should work in **SVG / Canvas / WebGPU**; how that drives morph-target
faces in the [Faceball Construction Set](../../apps/performance-space/faceball-construction-set.yml).

Nobody has to implement on air. Designs go in the repo. Others play later (*homefun*).
