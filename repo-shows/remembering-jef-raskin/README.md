## Memorial mode

**Subject:** Jef Raskin

We represent and discuss Jef's documented work only. We do NOT interview him or speak as him. Any living person on a produced episode requires their own consent — listing below is NOT an invitation.

## Frame

**Read the Intent.** Same move as the Engelbart memorial: resist the Macintosh-origin laundry list. Center the intent — protect the user's locus of attention, eliminate arbitrary cognitive load, never trap people in modes. What world was Raskin trying to create?

**Repo Show Synthesis.** See characters/jef-raskin/humane-interface-and-this-repo.md — brutalist listing + humane README overlay; inspectability without abandoning navigation that respects your head.

**Not a Cat.** Raskin wanted to hide the file system from casual users. We expose it as stage. The README layer is the honest compromise — museum prose on top, yaml girders underneath.
