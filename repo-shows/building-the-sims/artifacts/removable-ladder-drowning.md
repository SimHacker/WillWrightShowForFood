# Removable ladder drowning

## Hook

Pool ladder as placeable **pool piece** → player removes it → Sim cannot exit → drowns.

## Story

Pools used a **pool layer** plus **ladder objects** in the architectural pipeline. Ladders could be
removed in build mode while Sims swam — iconic player cruelty, memetic for decades.
