# Urn rings around the pool

## Hook

Remove the ladder, watch them drown — repeat until the pool deck is a **ring of urns**.

## Story

Player behavior + QA edge case:

- Multiple drownings on one lot → **tombstones and urns** accumulate around pool perimeter.
- Some reports filed as **bugs**; others accepted as emergent cruelty simulator.

## Ask on air

- Object limit on urns? Save bloat?
- Design intent vs discovered "sport"?
