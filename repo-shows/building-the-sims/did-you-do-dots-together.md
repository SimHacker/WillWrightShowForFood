# Did you Do Dots Together?

*Awkward reunion question — Jiminy Glick energy, audience in on the innocence.*

[Portrayal standards](../../schemas/portrayal-standards.md) · guests: Jim Mackraz, Eric Bowman

## The question

Don (or Glick-mode host), leaning in:

> **"So Jim… Bobo… after The Sims shipped — did you two *Do Dots Together*?"**

Pause. Let it hang. The phrase sounds worse than it is.

## What it actually means (verified company, team detail TBC)

**[DoDots](sources/dodots-post-sims.md)** (~2000) — desktop "dots" for Web mini-apps without a browser.
Stanford GSB [case study](https://www.gsb.stanford.edu/faculty-research/case-studies/dodots);
[CNN Apr 2000](https://edition.cnn.com/2000/TECH/computing/04/07/dodots.idg/index.html).

Don's account (*confirm with guests*): Jim and Bobo both worked at DoDots after The Sims.
Later Don recruited Bobo to **TomTom** Amsterdam — second reunion act.

## Performance (Glick makes it worse)

1. **Ask plainly** — as if checking a rumor from "the blogs"
2. **Jim/Bobo explain** — actual startup, actual dots, Kembel twins, Softbank, dot-com debt circus
3. **Host doubles down** — *"But WHAT did you DO? Together? With the DOTS?"*
4. **Explanations fail** — each clarification sounds more compromising
5. **Release valve** — someone reads the CNN headline aloud: *"DoDots: The Web without a browser"*
6. **Bridge** — TomTom Amsterdam; Bongo Bingo / iLoci trilogy; old band back together again
