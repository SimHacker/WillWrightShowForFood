# DoDots — post-Sims startup (verified company; team detail needs_confirmation)

## What DoDots was (public)

**DoDots** — dot-era Internet startup (~2000): small desktop "dots" for Web tasks without opening a
full browser. "The Web without a browser."

| Source | URL |
|--------|-----|
| Stanford GSB case study (2000, Case E89) | [gsb.stanford.edu — DoDots](https://www.gsb.stanford.edu/faculty-research/case-studies/dodots) |
| CNN / PC World (Apr 7, 2000) | [edition.cnn.com — DoDots](https://edition.cnn.com/2000/TECH/computing/04/07/dodots.idg/index.html) |

**Public facts from press:**
- Desktop "home dot" + partner dots (Merriam-Webster, MySimon, ZDNet, etc.)
- George & John Kembel (twin brothers) — CEO & CTO
- Softbank-led financing; Stanford case covers debt rounds and dot-com turmoil
- Windows IE 4+ beta; "desktop is just the start"
