## Elevator pitch

MOOLLM is an LLM operating system / orchestration layer — like LambdaMOO crossed with The Sims.

- Directories are rooms
- YAML files carry semantic comments (**yaml jazz**)
- Skills are inheritable prototypes
- Humans author canon; LLMs navigate, orchestrate, and write code when asked
- Repo Shows script and run inside this microworld
