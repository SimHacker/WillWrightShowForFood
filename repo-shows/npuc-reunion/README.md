# NPUC Reunion — New Paradigms for Using Computers

> Ted Selker's IBM Almaden workshop, reincarnated as a **Repo Show**: tapes, transcripts,
> character directories, runnable code — and **virtual IBM Burgers**.

**Host:** [Don Hopkins](../../characters/don-hopkins/README.md)  
**Co-host / archive keeper:** [Ted Selker](../../characters/ted-selker/README.md) 🔴

## What we're doing

NPUC was where people argued for interfaces the industry had not shipped yet. Ted Selker
organized it; Don spoke and demoed; Ted Nelson's 1996 talk is still legendary. Ted says he
has **seven years** of NPUC recordings.

This show digs up that archive, completes the guest roster **with Ted's help**, and builds
the reunion into the repo — not just a video.
