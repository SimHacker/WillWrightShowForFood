## Premise

A live simulation-bending cabaret competition. Each performer plays a
simulation as a visual instrument, improvised to music, drag-race style.
The costume logic is literal:
  - TILE SETS are the COSTUMES — each tile set is a costume change.
  - CA RULES + PARAMETERS are the ACTS — each automaton struts the same
    world through a different number in a different outfit.
Outrageous, flamboyant, Boogaloo Stu style cabaret — hand-made and
completely sincere. The city goes on in drag; the audience votes
merge or sashay.
