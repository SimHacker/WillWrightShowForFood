**Host:** Don Hopkins · **Status:** seed · consent not_yet_asked

**Centerpiece:** [**Live Comic Chat**](live-comic-chat.md) — private IRC room, emotion wheels,
panels committed into the show tree.

On **16 Jul 2026**, [microsoft/comic-chat](https://github.com/microsoft/comic-chat) went public
under MIT. Robert and Scott announced it; DJ created it and supported the release. This show asks
what we do with the source — and answers by **running Comic Chat live** with the creator and the
open-source agents.
