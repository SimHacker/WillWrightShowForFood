# Microsoft Comic Chat is now open source (16 Jul 2026)

**URL:** https://opensource.microsoft.com/blog/2026/07/16/microsoft-comic-chat-is-now-open-source/
**Authors:** Robert Standefer · Scott Hanselman
**Tags:** GitHub, Microsoft

## Pitch (blog)

Comic Chat (1996) turned IRC into comic panels — illustrated characters, speech bubbles,
expressions — and was the first real home of **Comic Sans** (Vincent Connare, 1994). Built in
Visual C++ 4.0 / MFC; shipped with Internet Explorer 3; later Windows 98 / MSN. Localized into
24 languages.

## Why open source now (blog frame)

Preserve a chapter of online-communication history; let historians, retro fans, and builders
explore. Alongside original snapshots: **AI-powered modernization attempts** — build with current
VS, connect to modern IRC, run on high-DPI Windows. Not polished re-releases; worked examples.

## Show hooks

1. Editorial AI before "AI" — real-time pose / balloon / panel decisions from text cues
2. Playful software that shipped at corporate scale
3. Modernization as preservation practice (not vibecoded rewrite theater)
4. GitHub as the delivery vehicle — same stage metaphor as a Repo Show
