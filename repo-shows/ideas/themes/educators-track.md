## The pattern

A Repo Show is a live, forkable, git-native performance. That makes it **assignable**. A teacher doesn't book a field trip to watch it — they assign students to **participate**:

- Fork the repo
- Create audience characters
- Ask questions via PR
- Implement features as coursework
- Watch commits land (or get lovingly reviewed and bounced) on air

GitHub-collaborative open source development is basic literacy now — for game devs, writers, designers, researchers — especially with Cursor and MOOLLM. **The show teaches it by being made of it.**

## Formats

| Format | Description |
|--------|-------------|
| **Critical play** | Bartle-style: play, write critique, discuss on-show — no code required |
| **Audience characters** | Students create persona dirs + PR; player-type taxonomy as rubric |
| **Homefun PR** | Questions between shows as PRs — the riff loop with a syllabus |
| **Feature coursework** | Semester project = feature branch; teacher grades branch; show merges best |
| **Game jam** | Weekend jams — HKU Utrecht, Breda UAS as Dutch hosts |
| **Data lab** | Lall format modernized: run Micropolis experiments, stream metrics, analyze in Sheets |

## Why it matters

| Angle | Point |
|-------|-------|
| **Labor ethics** | Real GPL code, real credit, real review — coursework, not spec work |
| **Idea-guy antidote** | Everything in git — public ledger of who did what |
| **Institutional bridge** | Teachers co-apply for NWO/SIA-shaped grants — educator lane = funding lane |
| **Literacy** | Git, PRs, code review, AI-assisted dev — osmosis from the show format |
| **Decades brewing** | SimCity-in-education since OLPC/Kennisnet — tooling finally caught up |
