# A Repo Show with Gary Drescher 👤 ★

> **Made-Up Minds, remade** — Piaget you can run, now with LLM grounding and Will Wright in the same pun.

**Gary Drescher**'s [*Made-Up Minds*](https://mitpress.mit.edu/9780262517089/made-up-minds/) (MIT Press, 1991) — his **MIT PhD** under **Marvin Minsky** — built the **schema mechanism**: minds **made up** from learned **schemas** (context → action → result), marginal attribution, synthetic items.

**Will Wright** teaches the same pun in play: players **make up minds** in Sims and Proxi. We'd love a crossover segment.
