## Topic

How do you teach the history of interaction? Brad's CMU 05-640 flew in sixteen pioneers whose guest lectures became the sixteen guest chapters of Pick, Click, Flick!; Roy's Western University course has students single-stepping the actual 1972 PIXIE code in a PDP-7 emulator. Lecture hall meets lab bench — reading the history versus running it.

## Beats

1. Curriculum show-and-tell: 05-640's syllabus across the years vs Roy's history-of-graphics course — what each teaches, what each skips, and why
2. The sixteen guest lectures → sixteen guest chapters: who came, what each taught, which lectures bent the course (Panopto archive as show material)
3. The resurrection demo, live: PIXIE's 1972 code stepping in SIMH — address switches to 22, press START (Heinz's thesis p.189 tip); students' reimplementation work
4. Testimony vs artifact: what a student learns from Atkinson in the room that no paper carries; what a student learns from single-stepping a light-pen loop that no lecture carries
5. Newman & Sproull ref 520 and the citation record: PIXIE as 'movable menu' — how teaching materials propagate (or drop) attribution
6. What does an interaction-techniques curriculum look like in the LLM era? Both professors answer
7. Dream extension: Heinz Lemke joins for a segment — the man both classrooms teach
