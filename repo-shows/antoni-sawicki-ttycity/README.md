## Pitch

Antoni Sawicki (Tenox) forked the freed Micropolis code and put SimCity in the
terminal: ncurses, engine untouched, one binary, four graphics modes from vt100
ASCII to Unicode emoji tiles, mouse support, playable over ssh at 80×24. It's
his SECOND Micropolis port (wintown already runs it on Windows NT RISC). This
is the Repo Show's home turf: a GitHub repo, a GPL lineage that credits Will
Wright by name, and a one-person dev story that proves the whole thesis.
