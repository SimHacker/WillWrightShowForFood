## Why this show

Comic Chat is a perfect Hanselman beat: **history that still runs**, modernized just enough to
teach, published where developers already live. The blog promise — explore, learn, build upon —
is also the Repo Show promise: conversation that leaves a **living tree**.

Don's HN angle: Comic Chat launched Comic Sans into the world; **The Sims 1 shipped with Comic Sans
and did ok** — playful UI typography as product, not sin. Visual conversation → comics in 1996;
visual conversation → git/GitHub collaboration in 2026.

Trio with [`robert-standefer/`](../robert-standefer/) and [`dj-kurlander/`](../dj-kurlander/).
