## Why this show

On **16 Jul 2026**, [microsoft/comic-chat](https://github.com/microsoft/comic-chat) went public
under MIT — 1996 IRC rendered as comics, Comic Sans's first real home, SIGGRAPH '96 paper,
Windows 98 bundling. Robert's [announcement](https://opensource.microsoft.com/blog/2026/07/16/microsoft-comic-chat-is-now-open-source/)
frames modernization examples (AI-assisted builds for current VS / modern IRC / high-DPI) as
**worked examples**, not polished re-releases.

He told HN the release story is interesting, hinged on being in the right place at the right time —
and that he is **not** the original developer (that's DJ). He has even used Comic Chat to draw a
conference talk: https://standefer.com/agent-platform-comic/about.html

**Will Wright Show For Food** is a **Repo Show**: the stage is a public GitHub repository. They
put history on GitHub; we want to talk about what builders do next — and how conversation can leave
a living tree instead of a dead mp4.

Trio with [`scott-hanselman/`](../scott-hanselman/) and [`dj-kurlander/`](../dj-kurlander/).
