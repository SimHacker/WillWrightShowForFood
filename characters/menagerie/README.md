# Menagerie 🎪

Pee-wee's Playhouse virtual guests — one soul, many roles across repo-shows.
Not necessarily from video games. Gallery patrons today; balcony hecklers tomorrow.

*Pyramid:* [`GLANCE.yml`](GLANCE.yml) · [`CARD.yml`](CARD.yml) · [`INDEX.yml`](INDEX.yml)

## How it works

1. **Soul** — each guest has `CHARACTER.yml` (Sims traits, Mind Mirror, attachments, §).
2. **Thin overlays** — MOOLLM imports point upstream; local `wwsff_overlay` records roles and gallery beats earned *here*. Protocol: [`MOOLLM-OVERLAY.yml`](MOOLLM-OVERLAY.yml).
3. **Casting** — gallery openings pull from this room plus [`../sims/`](../sims/) and [`../robots/`](../robots/). Roster: [`GUEST-ROSTER.yml`](GUEST-ROSTER.yml).
4. **Game cartridges** — grue, Snorax, Two-Toll demonstrate portable NPCs. Essay: [`GAME-CARTRIDGES.md`](GAME-CARTRIDGES.md).
