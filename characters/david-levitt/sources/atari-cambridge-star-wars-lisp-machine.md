# Atari Cambridge — Star Wars cabinet ↔ Lisp Machine (confirmed 2024)

**Scene:** Atari Cambridge Research Center (ACRC), early 1984 — same lab constellation as
[Cynthia Solomon](../../cynthia-solomon/), [Margaret Minsky](../../margaret-minsky/),
[David Levitt](../), [Alan Kay](../../alan-kay/), and the children's-computer / Logo / music / haptics work.

**Confirmed by:** [Bill St. Clair](../../bill-st-clair/) (email to Don, 5–7 May 2024), matching Don's
eyewitness memory and Bill's public LinkedIn / résumé. Full private thread:
DonHopkins green-room `green-room/bill-st-clair/`.

---

## What Bill built (his account)

Hired at ACRC for **Q1 1984** (between Germany and Thinking Machines) to turn the **Star Wars**
arcade game into a **turtle-graphics output device**:

- Burned a **new ROM** for the cabinet; they often swapped the **original ROM** back in to *play*
  Star Wars.
- Hardware: **vector graphics**; display persisted ~**half a second**, so the display list had to be
  redrawn often.
- Also wrote a **3D turtle system for the Lisp Machine** — steer the eye, see what it was looking at.
- Public résumé line (archived): Symbolics Lisp Machine code to use Star Wars as graphics output;
  **6805** code loader; 3D turtles; maze game (later jsMaze.com was a second try).

He **does not remember David Levitt** by name (short stint; years later elsewhere). That does not
contradict Levitt's ACRC presence — only Bill's recall after forty years.

## What Don saw

Visiting ACRC with **Devon McCullough**: a Star Wars cabinet with a **huge bus of ribbon cables**
running to a Lisp Machine. Indelible impression; never got to play that rig. Later owned a Star Wars
*console* in Mountain View — not the cabinet, not the Lisp Machine.

Public HN: [40261671](https://news.ycombinator.com/item?id=40261671) (Mike Jang / Star Wars cabinet
memorial thread, May 2024) · earlier memory [18803966](https://news.ycombinator.com/item?id=18803966)
(2019).

## Why it matters for Levitt (and the show)

- Places David in a lab that was not only Logo/music/haptics — it also did **arcade-hardware × Lisp
  Machine** hacks.
- Bridges Cynthia's **video trove** (Levitt on Lisp Machine doing musical improv) to a second ACRC
  Lisp Machine story with physical arcade iron.
- Show gag / segment fuel: *turtle graphics out of a Death Star cabinet* — constructionism meets
  vector-arcade persistence of vision.
