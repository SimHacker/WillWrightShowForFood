# Marvin Minsky — papers (primary sources)

Local copies of the AI Lab memos and papers this room and its MOOLLM cousins cite.
All scans from MIT DSpace ([AI Memos 1959-2004 collection](https://dspace.mit.edu/handle/1721.1/5460))
except Steps (CSAIL course mirror). Most are image scans with no text layer; K-lines and
Matter-Mind-Models have uncorrected tesseract OCR alongside, greppable.

Markdown sidecars sit next to the PDFs, each with a table of contents and one linkable
anchor per original section. Where Minsky released the text himself on his website
(Jokes, Matter-Mind-Models, Music-Mind-Meaning) the sidecar is his **full text**,
verbatim, reformatted for reading and linking. Where only the scan exists (K-Lines) the
sidecar is a **reader's guide** — section map, page pointers, key quotes — with the
uncorrected OCR alongside for search; the PDF stays the text of record.
