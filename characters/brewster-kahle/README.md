# Brewster Kahle

*Sniff:* [`GLANCE.md`](GLANCE.md) · **Invite:** [`invitation.md`](invitation.md)

**Brewster Kahle** — founder of the **Internet Archive** (1996), **WAIS** pioneer, and early web
preservationist. Co-founded **The Little Garden (TLG)** ISP in Palo Alto with John Romkey,
Steve Crocker, and **Tom Jennings**.

## Early web dreams (1996)

Marc Weber CHM interview with Tim Pozar and Brewster (29 October 1996). Brewster kept the **early WAIS
logs** — what people searched for when the web still felt like open frontier — arguing the medium had
already "stagnated" toward technician-defined limits, and that **early dreams** are what we should live up to.
