# Pre-show sessions — one-on-one recordings with Will (and friends)

Artifact home for the short, focused recordings: sound checks, discussions, intros,
chats. [`../videos.yml`](../videos.yml) is the INDEX — names, one-liners, pointers.
The RICH CONTENT lives here: each session directory holds its `SESSION.yml` (full
beats, discussion seeds, takes log, published links) plus transcripts, notes, and
excerpt manifests as they accumulate.

## Production philosophy

**Lots of low-pressure takes. Keep the best ones. Publish them.** Then cut both ways:

- **Short form** — excerpts, memes, blipverts; each take is quarry for many clips.
- **Long form** — edit sessions together with other videos and other people for
  **James Burke *Connections*-style narrative-arc storytelling**: documentaries,
  design expositions, and fundraising appeals. A take recorded today is a scene in
  arcs we haven't written yet — so takes are kept, logged, and tagged, not discarded.

Nothing here is throwaway: the sound check produces game audio, the tutorial produces
the tutorial, the chats produce the documentary. Rehearsals are releases.

## Sessions are organelles

Each session is a little mini-show — wrapped in a layer of lipid membrane and injected
into bigger, more complex shows. A teaser cut, a premiere segment, a documentary arc,
a fundraising appeal can each engulf a session whole; the membrane (this directory)
keeps it intact wherever it lands.

This isn't just how characters are modeled — it's how MOOLLM models everything:
objects as directory trees and files. Which is not meant to sound profound; it's
pedestrian and everyday, and that's the whole point. Lean into things we already do
every day — directories, files, copies, links — instead of inventing new things to do
stuff we already know how to do. Same shape as sub-souls (membranes within membranes):
a session inside a show inside an arc is a directory inside a directory inside a
directory, because it *is* one.
