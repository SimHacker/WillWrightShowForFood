# The Will Roll — batch recording script (20 takes)
# Record top to bottom in one sitting. Publish the full session as BTS; atomize clips for cutaways.
# Spec: will-roll.yml · Standards: ../../schemas/portrayal-standards.md

## How we make content

Same pipeline as shows and games: **script → voice → video → motion capture → atomize → reuse forever.**

- **This session:** one continuous take, Don reading trigger lines off-camera (or in-ear), Will reacting.
- **Deliverable A:** medium-length BTS — *"The Will Roll: Twenty Takes of Kind Eye-Rolling"* (in-takes, bloopers, the rare genuine huh).
- **Deliverable B:** 20+ isolated reaction atoms for infodump / Special Interest Theater cutaways.
- **Rule:** kindness always wins. Will is in on the joke. The joke is his kindness.

## Setup

| Item | Note |
|------|------|
| Camera | Tight on Will's face; room for eye-roll travel |
| Don | Off-camera or split — reads `DON (trigger)` lines only to cue |
| Slate | `WILL ROLL take NN — [card]` before each beat |
| Between takes | One breath. No apology. Keep rolling. |
| Take 20 | Save energy — the rare card must land clean |
