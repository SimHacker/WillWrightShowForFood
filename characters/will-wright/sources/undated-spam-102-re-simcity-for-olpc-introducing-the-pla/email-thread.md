        To get more specifics about OLPC, who should I contact?

Walter Bender is President of Software and Content.  But OLPC is a very
small organization (14 people, last time I looked); they try to do all
their work in public, and you can just look online to see what's up,
rather than them having to explain each thing to each person separately.

The OLPC wiki is a useful resource.  I recommend looking at these
pages for info about application software development.  Once you're
there, use the sidebar to browse the overview, table of contents, and
any other parts of interest for more general information about the
laptop and the OLPC project:

 http://wiki.laptop.org/go/Application_Developers
 http://wiki.laptop.org/go/Talk:Application_Developers
 http://wiki.laptop.org/go/Software_components
 http://wiki.laptop.org/go/Development_issues

 http://wiki.laptop.org/go/Hardware_specification 
 http://www.laptop.org/

The "Community News" link there leads you to the latest weekly newsletter,
which then allows you to see the whole archive of newsletters that
chronicle the progress of all aspects of the project.

Also, it would be helpful to know, giving the engineering work needing
to be done, when we need to have all particulars worked out so that we
can make the initial shipment of laptops and/or key publicity dates.

My guess is that if Don isn't occupied by other paying work, one to
two months of full-time effort would suffice to adapt the program
itself, starting after EA commits to releasing the code under a free
license.  Don will probably have a better estimate.  More time will be
needed to coordinate with OLPC to integrate the resulting code into
the OLPC software distribution, and to support the software as other
OLPC developers and users test SimCity and find problems in it.  Call
it three to four months of elapsed time from the moment of re-licensing.

 http://wiki.laptop.org/go/Software_Schedules

The schedule in the Software Schedules page is tentative, and only
goes thru the Btest-2 manufacturing release in January.  I've seen
another schedule that extends to actual shipment of first systems for
kids in summer 2007, but I don't have a URL in front of me; perhaps
Walter or Jim can update the wiki schedule, and/or give us a pointer to
that schedule.  My recollection was that the system and application
software needed to be frozen about a month before the mass production
run.  So, working backwards, if we assume mass production July 1,
freeze June 1, integrate April 1, start development by Feb 1.

OLPC has been through several hardware prototype releases: Atest,
pre-Btest, and Btest-1.  They built about 875 Btest-1 machines (many
of which are in the recipient countries, or are being tested to
destruction to improve the physical packaging).  Btest-2 is the next
upcoming hardware release, which will include custom display and flash
interface chips that were not available during Btest-1.  I think there
will be a run of Btest-3 and/or C-test machines before entering mass
production, but that's from memory.

Each hardware release has an associated software schedule, since the
hardware must come preloaded with software in its flash chips.  That
software can be upgraded later over the Internet or from a USB drive.
(Such updates become harder logistically once hundreds of thousands of
laptops are in the field in Libya, Brazil, Uruguay, etc.)

This page gives an overview of the state of the Btest-1 machines that
are currently in use by developers:

 http://wiki.laptop.org/go/BTest-1_Release_Notes

I'm very excited to be working on this and look forward to making it
work.

We all share your excitement.  It's a dramatic project with the potential
to change a lot of peoples' lives for the better.  Thank you for adding
some of Electronic Arts' capabilities to the effort.
