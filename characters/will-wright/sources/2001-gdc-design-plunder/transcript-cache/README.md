# Transcript cache — 2001 GDC Design Plunder

YouTube auto-captions for **timestamp verification**. Prefer **Cory Martin + slides** upload for any clip citing visuals.

## Refresh

```bash
yt-dlp --write-auto-sub --sub-lang en --sub-format vtt --skip-download \
  --extractor-args "youtube:player_client=android" \
  -o "youtube-auto-en.%(ext)s" "https://www.youtube.com/watch?v=c91IWh4agzU"
```
