# SimFaux — OpenLaszlo Fox News parody (2006)

*YouTube: https://www.youtube.com/watch?v=gRodlxUZ9SQ*

**App hub:** [`../../../../apps/simfaux/`](../../../../apps/simfaux/) — development, archives, media specs, Declare path. This Will-Wright source folder is a YouTube-bridge seed only.

Live simulated **Fox News** parody — pie menus driving talking heads, video mixing, picture-in-picture, overlays. **OpenLaszlo** for Flash player, 2006.

## Features (from Don's description)

- Pie menus control live simulated characters (talking heads, waving hands)  
- Video playback, multiple windows, PiP, special effects  
- Written in OpenLaszlo — same stack as SimFreaks CMS / Micropolis web client era
