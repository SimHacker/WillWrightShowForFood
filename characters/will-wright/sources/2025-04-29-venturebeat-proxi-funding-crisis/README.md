## Show beats (public-safe)

- **Deja vu structure** — Will explicitly compares Proxi pitch meetings to pre-Sims Maxis fights.
- **Mattrick anecdote** — "oil and water" but mutual respect; EA's *Keeping Up With the Joneses* echo.
- **Core tech group borrow** — four San Mateo engineers repurposed for Sims prototypes (Will, VB). Don was **hired** separately on team rec for animation/UI ([`don-hopkins witness`](../../../don-hopkins/sources/sims-origin-core-tech-four-1997.md)).
- **Scott McCloud** — abstract memory avatars so players project themselves (Understanding Comics).
- **Kevin Lynch** — five–ten mental landmarks; hometown memory map with geolocated shared stories.
- **Memory taxonomy** — people, places, time, feelings, things, activities.
- **24 vs 100 memories** — Wright's threshold for "really fascinating."
- **Platforms considered** — PC/PS5/Xbox; Roblox explored; blockchain rejected (too slow).
- **Breakthrough T1D** — public Proxi demo for charity (Dec, per article).
