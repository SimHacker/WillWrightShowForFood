# Steye Hallema 📱🪄🎬

*Portrayal standards:* [`../../schemas/portrayal-standards.md`](../../schemas/portrayal-standards.md)

**Steye Hallema** (b. 1976) — Dutch composer, director, inventor. Audience in the middle of the magic: phones as orchestra, cinematic VR that treats the viewer as a person in the room, volumetric intimacy.

## Why he’s in this repo

Sibling branch to **[Keez Duyves](../keez-duyves/) / PIPS:lab**. Same participation-not-observation root; Steye’s path went **PIPS:lab → VPRO Medialab → Jaunt XR creative director → Smartphone Orchestra / WildVreemd / 4DR**. Bridges Don’s Amsterdam PIPS circle to the Jaunt era with **[Arthur van Hoff](../arthur-van-hoff/)**.

## Public timeline (career)

| When | What |
|------|------|
| ~1999–2013 | **PIPS:lab** — composer, musician, writer, actor ([NEXT Conference roster](https://nextconf.eu/person/pipslab/) with Keez et al.) |
| 2015–2016 | Creative lead, **VPRO Medialab** |
| 2016–2017 | Creative Director, **Jaunt VR / JauntXR EMEA** (Amsterdam) |
| 2014– | Founder / CD **The Smartphone Orchestra**; WildVreemd |
| 2019– | Volumetric Director (freelance), **4DR Studios** Eindhoven |
| 2024/25 | Artist in Residence, **Nederlandse Filmacademie** VRAcademy |

## Signature works (public)
