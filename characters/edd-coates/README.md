# Edd Coates 🎮

*Portrayal of a real invitee, written by Don — not Edd.*
[Portrayal standards](../../schemas/portrayal-standards.md)

**Edd Coates** is a UK game **UI artist / UX designer**, toolmaker, educator, and archivist.
He is best known for the **[Game UI Database](https://www.gameuidatabase.com/)** — a searchable
museum of shipped game interfaces — and for **[PadCrafter](https://www.padcrafter.com/)**, a free
controller / keyboard layout builder. He is writing ***The Game UI Bible***
([Lost in Cult](https://www.lostincult.co.uk/); official announcement pending). He is a
**friend of [Don Hopkins](../don-hopkins/)**.

That is the short version. The longer one matters because the Repo Show audience includes players,
designers, archivists, and people who have never heard of a radial menu.

## Will Wright Show For Food — a Repo Show

A blog is a dead text-and-picture show. A podcast is a dead mp3. A YouTube channel is a dead mp4
plus a comment landfill. A **Repo Show** is a live GitHub repository: conversation *and* a tree of
files that can change — sources, sketches, runnable demos, issues, PRs — with a place for the
audience to hang out before, during, and after. ([Repo root](../../) · [characters](../) ·
[repo-shows](../../repo-shows/))

**[Will Wright](../will-wright/) is in** — signed on for the
[premiere](../../repo-shows/will-wright-premiere/README.md) and more.

Edd catalogs **what games actually shipped on screen**. Don preserves **executable** interaction
history — [pie menus](../don-hopkins/pie-menus-chi-88-and-beyond.md), SimCity / Sims shells,
[MicropolisCore](https://github.com/SimHacker/MicropolisCore),
[PieCraft](https://github.com/SimHacker/MicropolisCore/tree/main/documentation/designs/piecraft).
Same obsession, complementary media.

## Why Edd belongs in the show

1. **He already built the museum.** [GUIDB](https://www.gameuidatabase.com/) is what working designers open when they need receipts on how inventories, radials, settings, and HUDs actually look in the wild — hits *and* misses.
2. **He builds tools, not just decks.** [PadCrafter](https://www.padcrafter.com/) is the same instinct as the Repo Show: ship something people can use on Monday.
3. **He teaches in public.** Talks, university modules, a forthcoming book — literacy, not mystique.
4. **He pairs with Don’s thread.** [Pie menus](../don-hopkins/pie-menus-chi-88-and-beyond.md) (CHI ’88 → The Sims → [MicropolisCore PieCraft](https://github.com/SimHacker/MicropolisCore/tree/main/documentation/designs/piecraft)) need a cataloger who has *seen* every radial that shipped since. GUIDB is that catalog. Prehistory: [PIXIE on PDP-7](../../repo-shows/pixie-pie-menus-pdp7.yml) with [Heinz Lemke](../heinz-lemke/), [Lars Brinkhoff](../lars-brinkhoff/), [David Rosenthal](../david-rosenthal/).
5. **Ethical archives are the shared problem.** Screenshot museums and executable repos both get strip-mined unless creators set terms. That conversation is the show — Edd’s preferences lead; we cite GUIDB, we do not scrape it for training fodder. ([North star](game-ui-archive.md))

### The Gonzo / bridge hook (episode 2 spine)

[Soul City](https://github.com/SimHacker/moollm/tree/main/examples/soul-city) bridges characters and content between games ([hub/spoke index](../../repo-shows/INDEX.yml)). Bridge UIs should **look like the game** (skin) while sharing one ergonomic kernel (pies, tabbed frames, inhabited chrome) — see
[Gonzo UI Manifest](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/GONZO-UI-MANIFEST.md) · [federation peer games](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/federation-peer-games.md) · [nine-slice frames](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/ui-frame-nine-slice.md).

**Edd’s role in that story:** pull real GUIDB examples as redesign briefs. Keep the costume.
Replace bad hands. Multi-bridge sessions should read at a glance.
