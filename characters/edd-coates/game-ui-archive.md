## The headline

Two archivists, one obsession: **interfaces as cultural artifacts worth preserving** — with
**attribution**, **taxonomy**, and **consent** intact in the LLM era.

| Edd | Don |
|-----|-----|
| [Game UI Database](https://www.gameuidatabase.com/) — [Guinness](https://www.guinnessworldrecords.com/world-records/726866-largest-collection-of-videogame-interfaces) (42,706 / Nov 2022); archive still growing | [Repo Show](../../repo-shows/) — executable history in public GitHub repos |
| Screenshot + metadata + search | Runnable artifacts + [MOOLLM](https://github.com/SimHacker/moollm) skills |
| Built for **human designers**; AI training / scrape boundaries are Edd’s call | **Ethical AI data licensing** — cite, don’t scrape |
| *The Game UI Bible* ([Lost in Cult](https://www.lostincult.co.uk/); forthcoming) | [MicropolisCore](https://github.com/SimHacker/MicropolisCore), [Gonzo UI](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/GONZO-UI-MANIFEST.md), [PieCraft](https://github.com/SimHacker/MicropolisCore/tree/main/documentation/designs/piecraft), [The Sims pie lineage](../don-hopkins/pie-menus-chi-88-and-beyond.md) |

## Why this pairing

- Built the [Game UI Database](https://www.gameuidatabase.com/) during lockdown — Guinness Nov 2022; GUIDB 2.0 Aug 2024 ([Game Developer](https://www.gamedeveloper.com/design/game-ui-database-relaunches-with-new-features-video-support-and-over-55-000-screenshots)); archive still growing (see [README](README.md) for sourced numbers)
- [PadCrafter](https://www.padcrafter.com/) — free control-scheme tool working designers can share by URL
- *The Game UI Bible* — forthcoming with [Lost in Cult](https://www.lostincult.co.uk/)
- Pocket Gamer Best Tools Provider 2021; Game Dev Heroes — Game Design Hero 2021
- **Friend of Don** — [pie-menu archaeology](../don-hopkins/pie-menus-chi-88-and-beyond.md), [Gonzo reinterpret](../don-hopkins/queer-oui-for-the-straight-gui.md), ethical archive strategy
