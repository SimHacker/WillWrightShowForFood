**Proposed episodes** (one, both, neither, or remix):

1. **The Game UI Database & Ethical Archives** — taxonomy at scale; *The Game UI Bible*; PadCrafter; how curated UI archives should treat AI training / scraping; how independent archivists get paid fairly.
2. **Pie Menus, Gonzo UI, and PieCraft** — browse GUIDB live for what worked and what sucked; treat the misses as **redesign briefs** ([Queer Oui for the Straight GUI](https://github.com/SimHacker/WillWrightShowForFood/blob/main/characters/don-hopkins/queer-oui-for-the-straight-gui.md) — *Queer Oui for the Straight GUI* / *Put the SaS into SaaS*); keep each game's visual soul, swap in ergonomic pies and tabbed frames (**skinnable [Gonzo UI](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/GONZO-UI-MANIFEST.md)** for [Soul City](https://github.com/SimHacker/moollm/tree/main/examples/soul-city) bridges so multi-game sessions read at a glance); The Sims pies ([my firsthand thread](https://github.com/SimHacker/WillWrightShowForFood/blob/main/characters/don-hopkins/pie-menus-chi-88-and-beyond.md)); co-design the ultimate user-editable pie; **[PieCraft](https://github.com/SimHacker/MicropolisCore/tree/main/documentation/designs/piecraft)** as UI literacy through play.

3. **PIXIE → blinkenlights → PadCrafter** *(same night or a sequel)* — 1969 **PIXIE** radial menus on PDP-7 / Type 340 with a **light pen**; *Spacewar!* / vector-console ancestry; **Engelbart** mouse + chord keyset; **Lars Brinkhoff**'s PDP-7 emulator work and a **virtual light pen**; then the fun bit — use **PadCrafter** to design old-school computer **front panels** (switches, blinkenlights, RUN/STOP) as shareable control-scheme URLs for emulators. Seed: [PIXIE on PDP-7](https://github.com/SimHacker/WillWrightShowForFood/blob/main/repo-shows/pixie-pie-menus-pdp7.yml) · hooks in [ideas.md](https://github.com/SimHacker/WillWrightShowForFood/blob/main/characters/edd-coates/ideas.md)
