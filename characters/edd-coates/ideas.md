## Episode 1 hooks

### Building the Game UI Database

Lockdown 2020 → Guinness World Record (Nov 2022: 42,706 screens; now 73k+). Taxonomy design.
GUIDB 2.0 (Aug 2024): video, colour filter, image inspector. Industry adoption (Insomniac, Arkane,
Double Fine, Frontier, Compulsion, Ubisoft Montreal).

### Ethical AI data licensing — the anti-slop defense

GUIDB explicitly bans AI scraping. Opt-in **Truffle**-style corpora: expert-verified, attributed,
compensated. Protecting curation labor — metadata is the product, not raw pixels.

### The Game UI Bible

500+ pages, Lost in Cult, 2026. Translating interactive UI to print. Why a physical tome still
matters when interfaces patch weekly.

### PadCrafter 2.0

Controller layout / button UX standardization across PlayStation, Xbox, Nintendo. Toolmaker
mindset — from making UI to making tools for UI designers.

### Executable vs screenshot archives

Don's Repo Show runnable artifacts + Edd's visual museum = complement. Mapping Micropolis / The
Sims UI into GUIDB taxonomy.
