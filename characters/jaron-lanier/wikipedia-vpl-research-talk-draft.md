# Draft: Talk:VPL Research — what "VPL" stood for

Copy the fenced block below verbatim into a new section on
[Talk:VPL Research](https://en.wikipedia.org/wiki/Talk:VPL_Research)
(use "Add topic"). The `~~~~` at the end auto-signs. If you edit the
article directly instead, the same refs work in the article body.

Notes (do not paste): Wikipedia treats Lanier's Scientific American
article as a reliable primary source for the naming of his own
company — it was professionally published by SciAm, not a blog post;
the jaronlanier.com PDF is a courtesy copy of the published article.
The proposal deliberately keeps "Virtual Programming Language" in the
text so it's a correction-with-both-names, not a revert war.

```
== Name: "Visual Programming Language, or Virtual Programming Language" — current sourcing does not support "Virtual Programming Languages" ==

The article currently states: ''"VPL" stood for "Virtual Programming Languages"'', cited to Burbules (2006). Neither of the article's early citations actually verifies this expansion:

* The C-SPAN citation ("VPL Research | C-SPAN.org") is an organization video-listing page. It contains no expansion of the acronym anywhere, and neither do the transcripts of the two Lanier videos it indexes (''Digital Future'', April 2, 2015; ''Who Owns the Future'', May 15, 2013).
* Burbules (2006) is a tertiary mention in an education handbook, published 22 years after the company was founded, and gives no source for the expansion.

Jaron Lanier's own published account contradicts the article's flat claim. In "Virtually There" (''Scientific American'', April 2001), Lanier describes coining the name when a ''Scientific American'' editor required an affiliation for the September 1984 cover, which used one of his visual-programming experiments as its illustration:

<blockquote>I blurted out "VPL Research" (for Visual Programming Language, or Virtual Programming Language), and thus was born VPL. After the issue's publication, investors came calling, and a company came to exist in reality.<ref name="lanier2001">Lanier, Jaron. "Virtually There". ''Scientific American'', April 2001, pp. 66–75. Author's copy: https://www.jaronlanier.com/cocodexintro/lanier01sciam.pdf</ref></blockquote>

Note: singular "Language", not "Languages", and "Visual" given first — consistent with the name's origin in Lanier's visual programming language work (the [[Jaron Lanier]] article itself describes VPL as "a 'post-symbolic' visual programming language"). Period sources corroborate the visual-programming origin: the September 1984 ''Scientific American'' cover,<ref>''Scientific American'', September 1984 (special issue on computer software); cover illustration from Lanier's visual programming language.</ref> and a 1990s Street Tech profile reporting VPL was "rumored to stand for 'Visual Programming Language'".<ref>"VPL Research, Inc." ''Street Tech'' (beyond Cyberpunk profile), archived at https://static.anarchivism.org/streettech.com-bcp/BCPgraf/StreetTech/VPL.html</ref>

'''Proposed change''' — replace:

:''"VPL" stood for "Virtual Programming Languages".''

with:

:''According to founder Jaron Lanier, "VPL" stood for "Visual Programming Language, or Virtual Programming Language"; he coined the name when a ''Scientific American'' editor required an affiliation for the September 1984 issue, whose cover featured his visual programming work.''<ref name="lanier2001"/>

This keeps both expansions in Lanier's own order, attributes the claim, and replaces citations that do not contain the fact with one that does. If there are no objections or better sources, I'll make the edit in a week or so.
```
