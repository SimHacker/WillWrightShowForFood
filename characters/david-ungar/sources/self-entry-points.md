# Self / Ungar / Smith — entry points (verified links)

Curated starting points into the Ungar & Smith corpus, verified 2 Aug 2026. The master
index is the Self bibliography, which holds nearly every paper as PDF:

https://bibliography.selflanguage.org/

## The OOP-RISC claim, primary sources

| Paper | Link |
|---|---|
| Self: The Power of Simplicity (Ungar & Smith, OOPSLA '87 / LaSC '91) | https://bibliography.selflanguage.org/_static/self-power.pdf |
| Architecture of SOAR: Smalltalk on a RISC (Ungar, Blau, Foley, Samples, Patterson, ISCA '84) | https://dl.acm.org/doi/10.1145/800015.808182 |
| Organizing Programs Without Classes (Ungar, Chambers, Chang, Hölzle, LaSC '91) | on the bibliography index |
| Self (Ungar & Smith, HOPL III, 2007) — the retrospective | https://worrydream.com/refs/Ungar_2007_-_Self_(HOPL).pdf |

Patterson is on the SOAR author list, so the RISC lineage is one hop, not an analogy:
SOAR reduced the hardware instruction set for Smalltalk; Self reduced the semantic
instruction set for objects; both bet the compiler wins back the speed. The full argument
lives in [SELF-AND-MOOLLM](https://github.com/SimHacker/moollm/blob/main/designs/object-system/SELF-AND-MOOLLM.md)
(with this link list mirrored in its Primary sources section).

## The compiler line

All on the bibliography index: An Efficient Implementation of SELF (Chambers, Ungar, Lee,
OOPSLA '89 — maps); Polymorphic Inline Caches (Hölzle, Chambers, Ungar, ECOOP '91);
Debugging Optimized Code with Dynamic Deoptimization (Hölzle, Ungar, PLDI '92 —
"pessimization").
