# ClipRepo naming challenge — invent a word

Don's proposal: replace invisible clipboard with a **GitHub repo** — visible, versioned, forkable transfer, MOOLLMable.

**Forbidden:** ClipCity, ClipShow, ShowBoard, RepoBoard, ClipRepo — *oh hell don't EVEN try to make a FUCKING METAPHOR*

**Assignment:** invent a **new word** that captures and illuminates the problem and solution. Throw to guests + audience on *unnatural-selection*. Review Ted Nelson's brilliant rants and raves. 

---

## Constraints the word must satisfy


| Property             | Why                                               |
| -------------------- | ------------------------------------------------- |
| **Visible**          | Ted's anti-invisible-scrap                        |
| **Negotiated types** | ICCCM TARGETS without atoms                       |
| **Lazy / on-demand** | Stream only requested representations when needed |
| **Forkable**         | Git semantics                                     |
| **Showable on air**  | Demo in Repo Show without X11                     |

## Good direction (not final)

A word suggesting **transclusion** + **ledger** + **selection-set** without any of those syllables.
