## Story

| Beat | Detail |
|------|--------|
| School | Haberdasher's Aske's — FORTRAN on IBM 1401, one-week debug turn-round |
| Cambridge | 1968 — The Archimedeans, Mathematical Laboratory after midnight |
| Machine | PDP-7 with 340 display — linked to Titan as graphics peripheral (never figured out) |
| Games | *Spacewar!*, *Lunar Lander* — then Piet Hein *Hex* |
| Memory | 8K 18-bit words — code, data, and 340 display program squeezed together |
| **Punchline** | Sort-of playable **provided you let the machine win**. Try to win → machine cheats. Ran out of time to find the bug. |
| Finals | Titan accounts + Newton's method — machine code in index registers, marked down for Fortran rewrite |
| Career | Likely only UK graduates who knew computer graphics that year — Ph.D. Imperial, CDC 6600 + 274 display |

Same **PDP-7/340 + Titan** stack as [PIXIE](../../heinz-lemke/README.md) (~1969); David at Cambridge ~1970; met Wiseman.
