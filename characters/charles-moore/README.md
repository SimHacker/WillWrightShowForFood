## The HOMER contract

Sunset Gower, late 70s / early 80s. **[Peter Conn](../peter-conn/README.md)**
and **[Coco Conn](../coco-conn/README.md)** had a visual mixing console
with no software. They hired Forth, Inc. and got Moore.

Paul's memoir (the original page is 404; copy in his room):

> We hired Forth, Inc. and got Charles Moore, the inventor of FORTH to
> program the console host computer. I learned FORTH and worked with
> Charles. I programmed the 2K byte EPROM in each visual channels. On
> the Master Z80 system we ran PolyForth a multi tasking system in 32K
> bytes.

> I learned Object Oriented Programming without knowing it.

Coco's public account: she learned Forth from him too.

Don did not work with Moore. Parallel thread: Mitch Bradley / Open
Firmware at Sun, 1987.

This room is that contract — not a Forth encyclopedia. Career pointer:
