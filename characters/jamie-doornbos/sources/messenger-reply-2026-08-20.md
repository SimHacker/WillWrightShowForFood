REPO SHOW IN A NUTSHELL (same paragraph I sent Heather when she asked):

Instead of a show being a dead mp4 video, it's a live GitHub repo -- it can point to videos on YouTube, but also contains design documents, code, objects, and everything else, checked in BEFORE the show so people can read it before, during, and after. A repo is a living, breathing collaborative space: a "show" can have any number of episodes in any media -- video, audio, pictures, source code, Twitch streams.
