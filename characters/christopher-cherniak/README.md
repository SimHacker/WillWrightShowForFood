# Christopher Cherniak 🕯️

Memorial portrayal — **not** Christopher Cherniak. We *represent and discuss*; we never speak as him.
[Memorial standards](../../schemas/portrayal-standards.md#memorial-mode)

**Field:** Philosophy of mind and computation, Department of Philosophy, University of Maryland, College Park

Taught *Philosophy and Computers: From Logic to Thinking Machines?* — half
computation theory, half philosophy of mind, "not a programming course". Students
built Turing machines, ran a universal one, and wrote CARDIAC-style machine code
and abacus programs on PCs, with software his department wrote for the course,
then argued Turing, Lucas, Dennett, Putnam, Fodor, Block and Dreyfus in three
short papers. The Turing-test week set ELIZA and RACTER against Micro-SHRDLU.

## PCOMP

The course disk survives. [`sources/pcomp/`](sources/pcomp/README.md) keeps its
35 text files byte for byte; [`packages/turing/PCOMP.md`](../../packages/turing/PCOMP.md)
converts every machine and program to YAML Jazz and checks each claim the disk
makes about itself. They hold: BUSY5 takes 2,133,492 steps to print 1,915 ones,
Marxen's BB5 takes 11,798,826 to print 4,098, the UTM adds and runs the busy
beaver. Two of the samples have bugs. Every help file signs off "A program is
never completed, only released."
