## Excel as VPL — HN 22978454 (Apr 2020)

Primary thread: https://news.ycombinator.com/item?id=22978454  
Metaobject blog: https://blog.metaobject.com/2020/04/maybe-visual-programming-is-answer.html

Don's dimensionality thesis (curated from flame war):

| Class | Structure | Examples |
|-------|-----------|----------|
| Textual | 1D character stream | C++, Ruby, PostScript source |
| Visual | 2D+ grid or graph | Excel, Max/MSP, SimAntics, Snap! |

- **Excel** — 2D grid, continuous recalc, macro recorder (PbD); orders of magnitude more deployed than Ruby
- **Vi** — *V* = visual mode of `ex`; does not make C++ a VPL
- **Visual Studio / PSIBER** — visual tools for textual languages

HN comment Don endorsed — real dichotomy is **text vs graph**, not text vs visual:

> *"Text is graphics… The real dichotomy people are discussing is not text vs. visual but text vs. graph."*
