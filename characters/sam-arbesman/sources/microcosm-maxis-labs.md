## The hook

Sam's public project **Microcosm Industries** — *simulation toys in the spirit of SimCity* — and Don's
working brief **Maxis Labs 2** describe the same adjacent possible from two seats: Sam as complexity
scientist and institution cataloger; Don as Maxis toolchain author still shipping microworlds in git.

Chaim Gingold's July 2024 intro named Sam as "super into all things Maxis" and curious about a
**Maxis 2.0** fan reconstruction. **Maxis Labs 2** is the buildable version: not a tribute band, a
**research lab that publishes runnable toys**.

## Three lenses, one brief

| Lens | Contribution |
|------|----------------|
| **Historian** (Chaim) | *Building SimCity* — how Maxis put the world in a machine |
| **Complexity scientist** (Sam) | When systems are overcomplicated; catalogs of what institutions should exist |
| **Engineer** (Don) | MicropolisCore, Soul City, CAM6, federation — code on main |

## What Maxis Labs 2 ships (proposed)

- **Glass-box simulation toys** — rules readable, forkable, teachable (SimCity spirit, 2026 substrate)
- **Institution as repo** — Overedge-shaped: inspect before you partner; fork before you pitch
- **Data portability** — Will's 1996 crown jewel as lab charter, not stretch goal
- **Harvest pipeline** — live conversation → cauldron → MOOLLM skills students can run

## Show beats

1. **Sam solo video** — names the design brief; what a modern Maxis-like lab optimizes for
2. **Don host weave** — demos what already runs (Micropolis, character rooms, YAML cast)
3. Optional **Will solo** — premiere arc; what he would fund if the lab were real
4. Optional **Chaim solo** — history vs complexity vs toolchain

## Not competing with Chaim's book show

Chaim's show is *Building SimCity* as spine. Sam's show is **institution design forward** —
Microcosm meets Maxis Labs 2. Same family album, different tracks.
