### Open-source SimCity — planted in Q&A

Stewart Brand curated written audience questions. **Dan Ancona** and **Mark Live** submitted the same
question (stacked twice): open-source SimCity so players can see and change the rules.

Will on stage: **very open** — SimHealth already exposed rules; arguing with the simulation means it
worked.
