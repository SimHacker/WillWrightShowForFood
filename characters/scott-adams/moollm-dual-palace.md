# Two careers, one adventure compiler

*The north star for a Repo Show with Scott Adams — grounded in Jan 2026 email + HN reconnect.*

## What MOOLLM is for (here)

MOOLLM is not "LLM chat with extra steps." It is a **microworld OS**:

- **Directories are rooms.** Walk with `cd`; the filesystem is the map.
- **YAML files are objects** with behavior — comments carry meaning (YAML Jazz).
- **Skills are inheritable protocols** — GLANCE → CARD → SKILL, like adventure verbs.
- The **adventure compiler** turns room graphs into **self-contained browser pages** anyone can play without cloning the whole repo.

Scott invented this shape in **1978**: adventure-as-**database**, tiny **interpreter**, ship everywhere.
Don followed into **Logo Adventure** (Logo REPL as parser) and now **MOOLLM**.

2. **Compile a room** — YAML in, single HTML/JS page out (adventure compiler pipeline).
3. **Author together** — Scott dictates one biography room (public fact); Don types YAML; page ships before credits.
4. **Parallel palaces** — fork Don's palace grammar for Scott's biography; compare verb-noun gates vs. LLM narration layer.
5. **HN Room One** — compile the [`29330901`](https://news.ycombinator.com/item?id=29330901) reunion thread as a two-room homage; prize is a transcluded essay clip.

**Show, don't tell.** The stream ends with something **playable** in the browser.
