## What Don argued (Room One thesis)

1. **Adventure games ≈ Method of Loci** — rooms, exits, objects, inventory as a geographic memory palace.
2. **Counterfactual UI:** What if adventure-map UIs had won instead of hierarchical DOS/Unix/Windows trees?
3. **Lineage he lived:** Scott's games → Logo Adventure (C64 Terrapin) → Zork/MUD/TinyMUD/MOO/LambdaMOO → pie menus as **radial two-way room exits** (not one-way menu trees) → DreamScape (WWDC 1995) → MediaGraph (Stupid Fun Club / Will) → iLoci (2008).
4. **Code as place:** Functions as shops/buildings (front door = params, back exit = return); Nassi–Shneiderman as floor plan.
5. **Filesystem as MUD:** Namespace as sprawling rooms/containers, not only a strict hierarchy.
