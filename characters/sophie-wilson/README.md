# Sophie Wilson 🦾 *(BBC Micro; ARM; Firepath)*

*Invitation portrayal — not Sophie Wilson.*
[Portrayal standards](../../schemas/portrayal-standards.md) · authored by Don Hopkins

## Who

**Sophie Wilson CBE FREng FRS** — Acorn architect of the BBC Micro / BBC BASIC line;
designer of the **ARM1** instruction set with Steve Furber; later Firepath architect
at Element 14 / Broadcom. CHM Fellow 2012.

## Why invited

The education micro and the phone CPU share one designer. Cambridge invention culture
sits next to this project's PIXIE / Rainbow memorials — different stacks, same city.
