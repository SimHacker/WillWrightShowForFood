## Why a Repo Show dream guest

Knuth's literate-programming claim is our house doctrine in older clothes: **explain to humans what
you want a computer to do** — documentation containing code, sections ordered for understanding,
then tangle for the machine. Repo Show / [MOOLLM](https://github.com/SimHacker/moollm) extend that
instinct to GitHub as a navigable adventure stage (rooms, characters, props as files).

Adventure-in-CWEB is the proof he already cared about the founding interactive-world schema enough
to museum it in literature.

## Contact reality (respect it)

Knuth **does not answer unsolicited email** (book-error reports only). Public protocol:
[Knuth versus Email](https://www-cs-faculty.stanford.edu/~knuth/email.html). Any real invitation
would be a **paper letter**. Status here: **dream guest** — portrayal + draft ready; no ask sent.
