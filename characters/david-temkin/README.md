# David Temkin

Invitation portrayal — **not** David Temkin. [Standards](../../schemas/portrayal-standards.yml)

**Field:** Founder/CEO/CTO of Laszlo Systems — created OpenLaszlo (LZX RIA platform); later co-founded Cola

[Invitation](invitation.md) · [Show seed](../../repo-shows/openlaszlo/README.md) · [CARD](CARD.yml)

David founded **Laszlo Systems** (2000) and created **OpenLaszlo** — the **LZX** XML+JavaScript
language and Presentation Server for rich internet applications, which compiled to Flash or
DHTML/Ajax and was open-sourced in 2004. He later co-founded the mobile-communications company
**Cola**. Don worked with him (alongside Henry Minsky and Oliver Steele) on OpenLaszlo.

Recently — per Don, relayed from an email to Henry Minsky — David **used AI to rewrite the OpenLaszlo
Java code so it compiles and runs again**: a striking feat of retrocomputing that could bring LZX
apps and demos back to life, and the spark for a whole [OpenLaszlo Repo Show](../../repo-shows/openlaszlo/README.md).
