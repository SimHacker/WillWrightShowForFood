# Sarah Allen — conversation hooks

*Menu, not homework. Pick any, skip the rest.*

## 1. Run the 2006 video components on OpenLaszlo 5.0 — live

Temkin's Software Preservation Society build means Don's mediastream/mediadevice
components — the ones you contracted and code-reviewed — can plausibly run again in a
browser, twenty years later. Preservation by RUN, with the original reviewer watching.
The YouTube player too, if the API gods smile.

## 2. API design as public craft

The 2006 laszlo-dev thread is a miniature masterclass: `stream` → `mediastream` (you
wanted the word back), camera+mic → `mediadevice`, `mute` → `capturing` ("'deaf' and
'blind' would be more descriptive but that's just too anthropomorphic"), hiding Flash's
conflated permission callbacks behind a portable API. How much of good API design is
just arguing about names in public, on the record?

## 3. After Effects 1.0 → Shockwave → Flash Video — the lineage everyone streams

CoSA to first Shockwave player to Flash Communication Server from inception: you built
the pipe the web's video flowed through for fifteen years. What did FMS get right that
WebRTC relearned the hard way?

## 4. Cinematic Interaction Design — the Interaction08 thesis

Inspirations from cinema for web application design. Repo Shows stage software the way
you staged interfaces; MOOLLM's "Stage Magic" pyramid is the same instinct. Where does
cinematography belong in an AI-era interface — and is a chat window just a locked-off
camera?

## 5. Bridge Foundry — "the software industry was created by women"

RailsBridge with Sarah Mei → Bridge Foundry: hundreds of workshops, dozens of cities,
culture change by open-source curriculum. Plus the 2007 ENIAC programmers fundraiser you
organized with Jean Bartik in the room. History gets forgotten fast; this show is a
memory machine — what should it remember on purpose?

## 6. Government as a codebase — Smithsonian, 18F, College Scorecard

Crowdsourced transcription at the Smithsonian; College Scorecard shipped while you were
mid-talk in Taiwan; "Transparency Wins." Open source as a way of working, not a license.
What transfers from open-source process to institutions — and what doesn't?

## 7. Webtop — the web desktop before its time

Mail and calendar as a rich internet application, licensed to telcos, years before Gmail
made it normal. The road-not-taken thread of the OL reunion is yours by right.

## 8. Designing for fun

Mightyverse, ¡Dígame!, theories of play, "epic win" framing. Don's Sims lineage next to
your language-game lineage: what makes learning feel like play instead of homework?
