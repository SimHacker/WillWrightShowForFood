# Yoot Tower inquiries — reply template

Public-safe boilerplate for fans asking about **open source**, **iPad / modern ports**, or **progress**.
No promises; same stance as [yoot-tower-discussion.yml](yoot-tower-discussion.yml).

**Exemplar exchange:** Luke Renner, 2026-07-14 — asked about open sourcing for iPad; Don replied with
the template below; Luke came back enthusiastic (and mentioned giving SimCity another try).

---

## When to use

- Email / social DM: "When will Yoot Tower be open sourced?" / "iPad port?" / "How's progress?"
- HN / Reddit follow-ups after [Don's Yoot Tower announcement](https://news.ycombinator.com/item?id=40050799)
- Anyone who loved SimTower / Yoot Tower and wants a legal, maintained edition

**Do not** promise dates, Nintendo outcomes, or Yoot's consent — Don spoke to Yoot recently; licensing
is real and slow.

---

## Copy-paste reply

```
I spoke to Yoot about it recently. There are some issues with Nintendo and licensing that may take
some time to work through. My fingers are crossed, but it might take a while and require patience.
We all want it to happen though!

Meanwhile I'm working on Micropolis (open source SimCity) and also reimplementing The Sims
character animation system and object creation tools with WebGPU. ;)

https://micropolisweb.com

https://github.com/SimHacker/MicropolisCore

https://vitamoo.space

https://github.com/DnfJeff/SimObliterator_Suite/tree/main/vitamoo

It's all still a work in progress I work on when I have spare time, so no ship date known! ;)

-Don
```

## Optional add-ons

**If they mention SimCity specifically** (Luke: "I was a little young when SimCity came out"):

```
Micropolis is a great place to start — same spirit, fully open, runs in the browser today.
```

**If they ask about SimTower vs Yoot Tower:**

```
Patrick Hulin did a beautiful clean-room SimTower reimplementation in TypeScript (tick-identical to
the original) — https://towers.world · https://github.com/phulin/tower-together — that's SimTower,
not the Yoot Tower sequel, but it's the same elevator-sim core and a friendly collaboration opening
if Yoot Tower licensing ever clears.
```

**If they offer to help:**

```
Thanks — the best help right now is patience on Yoot Tower licensing, and trying / filing issues on
the open projects above if you hit bugs. I'll loop you in if there's a call for testers on a Yoot
Tower path once Yoot and the lawyers are happy.
```
