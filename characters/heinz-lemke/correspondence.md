### PIXIE source listing (7 Jul 2026)

From Nagoya, CARS 40th — Heinz reveals **complete PIXIE program**: ~5000 words Assembler/Machine code, PDP-7 + DEC 340, light pen, interrupt management, interactive model building.

**Correction:** PDP-7 was NOT a dumb display terminal for Titan — 5000 instructions interactively built graph-theoretic models (3000 words remaining) for circuits, syntax graphs, control systems, then sent to Titan for simulation. DSHR (4 Jul) had reasonably read p.465 as dumb terminal; Heinz's author memory + listing supersede the diagram.
