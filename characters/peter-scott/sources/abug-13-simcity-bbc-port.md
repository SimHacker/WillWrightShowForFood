## The hook

Peter Scott's **BBC Micro SimCity port** (~20K memory, ~9–12 months) is his proudest technical
achievement — and includes a **phone call with Will Wright**: *"BBC has 20K memory" / "Seriously?"*

## Person

Bedlington, Northumberland ("25 pubs"). 1980s Acorn scene → 1990s TV → animation → freelance (2021 talk).
Contemporaries: Gary Partis (mentor), Daryl Still (Audiogenic), Richard Hanson (Superior Software).

## SimCity port

| Field | Detail |
|-------|--------|
| Memory | ~20K BBC Micro — "entire game a tenth the size of a Mac icon" |
| Materials | Box files, algorithms, drawings, every city tile — "kitchen sink" |
| Implementation | Mostly 6502 assembly; BBC BASIC for loop edges; year-end reuses display RAM |
| Design tweak | European fairness — services + taxes both matter vs American low-tax defaults |
| Sales | Steady long tail; royalties years after |

> "SimCity conversion would fit into a tenth of the size of an icon on my Mac — the entire game."

## Pseudonym Dylan

Audiogenic 12-month non-compete. Checkbook signature stamp — paw print took ages at signings.
Superior knew; contractual caution.
