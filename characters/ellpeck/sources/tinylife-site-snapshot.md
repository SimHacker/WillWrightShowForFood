## The hook

Isometric pixel life sim — households, needs, skills, relationships, open world. **Queer-led**;
pronoun/gender/reproductive independence; Safe In Our World partner. Ships **sharing** that Sims 1
Legacy Collection removed.

## Game features

- Export/import households and lots with story descriptions.
- Steam Workshop for lots, households, worlds, C# mods.
- C# modding API; Example Mod; docs accept community PRs for tutorials.
- Worlds: Maple Plains City, Lunar Grove, Lavender Park, Demoville + custom maps.

## Contrast with Sims Legacy gap

| Tiny Life has | Sims 1 Legacy lacks |
|---------------|---------------------|
| Workshop + export/import | Exchange button, upload hooks |
| Mod API + story text on shared content | Sims Creator |

See [legacy-collection-exchange-gap research](../../will-wright/sources/sims1-legacy-collection-exchange-gap/README.md).

## Distribution

- Workshop: Subscribe → loads from Steam.
- Manual: Mods zip → `Mods/`; lots/households json → respective folders; maps zip → `Custom Maps/`.
- **Soul City federation:** indexes Workshop items + git-native mod repos as CARD metadata — drives
  players to buy Tiny Life without replacing Ell's Workshop.
