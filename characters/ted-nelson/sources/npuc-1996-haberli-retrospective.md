## Technology clock (what did NOT exist yet vs nascent)

| Capability | ~1996 status |
|------------|----------------|
| **JavaScript** | **Nascent** — Netscape shipped JS in **Dec 1995** (Mocha → LiveScript → JavaScript). Browser script age **just born**. |
| **Java applets** | 1995 announce; write-once run-anywhere hype peak |
| **CSS** | **Dec 1996** W3C — likely **not** in this talk if early 1996 |
| **HTML 4** | 1997 |
| **XML** | 1998 |
| **JSON** | Douglas Crockford popularizes **2000s** — not in play |
| **Web "apps"** | Documents + forms; no SPA model |
| **Netscape Navigator** | Dominant browser; IPO **1995**; Marc Andreessen era |
| **Xanadu / ZigZag** | Ted's model — not the web's model |
| **MOOLLM / LLM agents** | Not even science fiction in product form |

**Tension:** Ted's **visible transclusion** and **two-way links** vs Netscape's **one-way web** and
**lossy copy-paste** document model. Haberli as Netscape voice = the branch that **won** (and we know
how Netscape turned out).

## The exchange (Don's memory)

Tense back-and-forth between Ted's hypertext vision and Netscape's pragmatic web stack — personal
information managers vs browser-as-platform. Don was there; felt the temperature in the room.

**Variant phrases:** NPUC transcript has **"cram and bum"** vs Engelbart **"cram and vomit"** —
clipboard rant family.

---

## Netscape aftermath (context for retrospect)

- Browser won; Xanadu didn't ship as product
- Netscape → AOL → Mozilla fork (1998) — open-source survival ironically preserved web stack Ted opposed
- JavaScript became the **linguistic motherboard** of the client — not PostScript, not ZigZag

## Is MOOLLM what Ted was talking about?

| Ted's PIM / hypertext beat | MOOLLM echo |
|----------------------------|-------------|
| Personal information **managers** | MOOLLM microworld OS; skills as agents |
| **Visible** connections | YAML jazz; transclusion; git-visible history |
| Documents as **places** | Directories as rooms |
| User-created structure | Repo Show audience checks in characters |
| **Will Wright** simulation/play | Characters, motives, places, objects, storytelling |
| AI as **agent** not oracle | Skills; bounded tools; not invisible clipboard |

**Don's thesis (respectful):** MOOLLM is a **possible realization** of Ted's PIM dream — but with
**play**, **simulation**, **characters**, and **user-authored worlds** (Will Wright lineage) that Ted's
1996 talk didn't emphasize. Not claiming Ted endorses — **ask on air**.

Contrast: web won with **lossy copy**; MOOLLM tries **visible forkable state**.
