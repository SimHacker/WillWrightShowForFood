# Ivan Sutherland ✏️ *(hero · Sketchpad north star)*

*Hero portrayal — we honor and cite Ivan Sutherland; we do not speak as him.*
[Portrayal standards](../../schemas/portrayal-standards.md)

**Ivan Edward Sutherland** (b. 1938) — **Sketchpad** (MIT 1963) invented interactive constraint
drawing on the TX-2; **Sword of Damocles** (1968) head-mounted display; co-founded **Evans &
Sutherland**; taught at **Utah** while Alan Kay was a student; Turing Award 1988; still researching
async circuits at Portland State ARC with Marly Roncken.

## Why this room exists

Sketchpad is a **north star** for this project: light pen, constraints, master/instance, zoom —
the ancestor line we measure PIXIE, Kay's proto-OOP, NeWS, pie menus, and educational geometry
software against. **Not** an interview ask by default (`invitation: not_offered`).
