## Why this room exists

**Ivan Sutherland** is one of the project's **heroes**. [**Sketchpad**](https://en.wikipedia.org/wiki/Sketchpad)
(1963, MIT) is a **north star**: light pen, constraints, direct manipulation, interactive drawing
as engineering — the ancestor line we measure PIXIE, NeWS, pie menus, and educational geometry
software against.

## Lineage we track
