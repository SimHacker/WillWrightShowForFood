Wavell Watson wrote *The Pervert's Guide to Computer Programming Languages* (SXSW 2017): Lacan
and Žižek applied to why we really choose languages. The title is a Žižek homage; the framework
is serious; the diagnosis chart is unforgettable:

- **Psychopath** languages — rules don't matter, ship it: JavaScript, PHP, VBA, SQL
- **Masochist** — look how disciplined I am: C, Assembly, Ada, Brainfuck
- **Sadist** — admit your impotence: Perl, Regex, Erlang ("nine nines"), Clojure
- **Obsessional** — a little monotony now avoids pain later: Java, C++, Haskell, Go
- **Hysterical** — look how beautiful this is: Python, Ruby, C#, Elixir
- **Fetishist** — have you tried more types/objects/abstractions: Smalltalk, Erlang, Factor
- **Melancholy** — a loss of a loss, romance about the history: Lisp, Scheme, Smalltalk
- **Depression** — enjoyment retrieved from reminiscing the loss: COBOL

In Lacan's usage "pervert" means a vessel of the rules — not an insult. The analyst's discourse
is the pervert's discourse. Choosing a language is a libidinal act before it is a technical one.
