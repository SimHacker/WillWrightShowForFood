# David Henkel-Wallace 🦫

*Sniff:* [`GLANCE.md`](GLANCE.md) · [`ideas.md`](ideas.md) · [`invitation.md`](invitation.md)

Decades of public sparring and mutual footnoting on Hacker News — the Wingnut naming story, the Space Cadet nitrous rumor, PLEASE-REMOVE-ME, Atari Cambridge videos: [`sources/hn-interactions.md`](sources/hn-interactions.md).
