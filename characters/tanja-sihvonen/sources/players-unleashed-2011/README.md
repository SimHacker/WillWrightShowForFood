## Thesis (one paragraph)

First academic monograph on **The Sims** modding — how players create and add custom content
(partial and total conversions), negotiate game code, and extend the domestic simulator beyond
EA's design. EA's Nancy Smith quote: cultural phenomenon thanks to *"openended creative freedom."*

## Chapter index (for show prep)
