## Slogans

**Queer Oui for the Straight GUI**

A user interface makeover show with designer fags and dykes!

**We put the SaS into SaaS!**

- We'll make your Peoplesoft hard.
- From SAP to Slay.
- Turning CRUD into Stud.
- We don't just redesign workflows — we *werk* flows.

For Jojo-quality UI criticism (POSEUR kits, XYmorph, boraX, XBorges — snow in hell), see sibling
[Jojo on UI](jojo-on-ui.md) (Joseph Francis; [UNIX-HATERS mirror](https://home.hccnet.nl/j.bus/unix-haters/x-windows/jojo-on-ui.html)).

Phonetic steal from *[Queer Eye for the Straight Guy](https://en.wikipedia.org/wiki/Queer_Eye_for_the_Straight_Guy)* — **oui** is French for *yes*, and also
*[Oui](https://en.wikipedia.org/wiki/Oui_(magazine))* (the men’s porno mag, US edition of French
*[Lui](https://en.wikipedia.org/wiki/Lui_(magazine))*). Rescue clinic slogan: say *yes* to queer
ergonomics for the straight chrome.

**SaS = Soul and Skin.** Stuff it into sterile **[SaaS](https://en.wikipedia.org/wiki/Software_as_a_service)**
chrome — the flat blue-pill strip that could belong to any product ([Gonzo fear](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/GONZO-UI-MANIFEST.md)).
Enterprise punchlines above are the same joke aimed at [PeopleSoft](https://en.wikipedia.org/wiki/PeopleSoft) /
[SAP](https://en.wikipedia.org/wiki/SAP) / CRUD dashboards: keep the business object, replace the
dead hands. [Gonzo](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/GONZO-UI-MANIFEST.md)
keeps the game’s **soul** (what fans recognize in the first second) and the **skin**
([costume tokens](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/ui-frame-nine-slice.md) /
nine-slice / type), while replacing the **hands**
([gesture](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/gesture-space-and-pie-menus.md),
[Fitts](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/pie-menus-fitts-law.md),
[pies](https://github.com/SimHacker/MicropolisCore/tree/main/documentation/designs/piecraft),
[tabs](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/notes/PIE-TAB-WINDOWS.md),
visible state).


| Direction        | Patient                                                             | Cure                                                                                                                          |
| ---------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Game → SaaS rot  | Distinctive game face, awful hands (or “calm” that deleted handles) | Keep costume; [Gonzo](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/GONZO-UI-MANIFEST.md) hands |
| SaaS → needs SaS | Generic enterprise / web chrome with no soul                        | Inject Soul and Skin — inhabited, skinnable, not another dashboard twin                                                       |


## Premise

Many shipped UIs look distinctive and feel awful — or feel like every other SaaS and have no soul
left. Skinnable [Gonzo UI](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/GONZO-UI-MANIFEST.md)
lets us **keep the face, replace the hands** — put the SaS into SaaS. Live citations from
[GUIDB](https://www.gameuidatabase.com/); never scrape ([archive ethics](../edd-coates/game-ui-archive.md)).

## Live format

Edd picks a beautiful-but-painful [GUIDB](https://www.gameuidatabase.com/) screen → whiteboard
([ep.2 seed](../../repo-shows/edd-coates/pie-menus-piecraft.yml)):

1. What is the **costume** / **SaS**? (palette, panel silhouette, icon grammar, typography — soul +
  [skin pack](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/GONZO-UI-MANIFEST.md))
2. What are the **hands** doing wrong?
  ([Fitts](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/pie-menus-fitts-law.md),
   modes, moving targets, modal traps, mystery meat —
   [classical HCI vs aesthetic UI](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/classical-hci-vs-aesthetic-ui.md))
3. Gonzo rewrite: [pies](https://github.com/SimHacker/MicropolisCore/tree/main/documentation/designs/piecraft) /
  [tabs](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/notes/PIE-TAB-WINDOWS.md) /
   bounce / visible state — same soul, better
   [gesture](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/gesture-space-and-pie-menus.md)
4. Would that redesign still pass as “that game” to a fan in the first second? (If the patient was
  pure SaaS: would it finally feel like *something*?) Bridge check:
   [Soul City](https://github.com/SimHacker/moollm/tree/main/examples/soul-city) multi-spoke glance.

## Candidate failure families

Edd fills with real [GUIDB](https://www.gameuidatabase.com/) citations:

- Mystery-meat radials / wheels with no rehearsal path ([gesture space](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/gesture-space-and-pie-menus.md) · [PIXIE ancestry](../../repo-shows/pixie-pie-menus-pdp7.yml))
- Inventory grids that fight [Fitts](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/pie-menus-fitts-law.md) and bury costs
- Modal stacks that trap the world under a dialog
- Settings walls that hide state the player needs mid-action
- Controller schemes that assume PC mouse muscle memory (or vice versa) — [PadCrafter](https://www.padcrafter.com/) as the legibility cousin
- “Calm” chrome that deleted scrollbars and handles ([classical HCI](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/classical-hci-vs-aesthetic-ui.md))
- Sterile SaaS-in-a-game-costume (or game-in-a-SaaS-costume) — no SaS left ([Gonzo directive](https://github.com/SimHacker/MicropolisCore/blob/main/documentation/designs/GONZO-UI-MANIFEST.md))

## Show etiquette

Anti-pattern: dunking for sport. Pattern: **redesign briefs with attribution** — cite
[GUIDB](https://www.gameuidatabase.com/), keep costume, fix hands
([brainstorm heartbeat](../../process/brainstorm-heartbeat.md): jam designs; others may implement).
