## Raster Masters @ Grateful Dead ("Grateful Dead Conferences")

Don's mega-comment on [HN 33105030](https://news.ycombinator.com/item?id=33105030) (Oct 2022, reposted 2025):

- **Raster Masters** lugged **million-dollar SGI Onyx** rigs from HQ across **North Shoreline Blvd** to **Shoreline Amphitheater** — sometimes toured with the Dead
- Live improvisational psychedelic graphics behind the band — **Electropaint**, **Panel Library** (NASA Ames lineage)
- Software like a **musical instrument**; taping/sharing culture mirrored Dead scene
- Hippie at show: *"I took all these shrooms… you would not fucking believe…"* — Don: *"I hadn't taken any shrooms, but I could see the exact same thing!"*

## CAM-6 / MicropolisWeb — CA performance to music

Inspired by **Toffoli & Margolus**, *Cellular Automata Machines* + Rudy/Josh lineage.

| Demo | URL |
|------|-----|
| CAM-6 simulator | https://www.youtube.com/watch?v=LyLMHxRNuck |
| CAM-6 site | https://donhopkins.com/home/CAM6 |
| SimCity tile CA chill | https://www.youtube.com/watch?v=319i7slXcbI |
| Micropolis Web CA music | https://www.youtube.com/watch?v=BBVyCpmVQew |
| **Play live** | https://micropolisweb.com/ |

**Controls (MicropolisWeb):** Space = toggle SimCity/CA; digits = speed; 0 = pause; +/- = tile sets.

Don's thesis: decades of work so you can trip on **pauseable, closable-tab** generative art — *"you don't need the harder stuff."*

**Chaim Gingold:** [SimCity Reverse Diagrams](https://smalltalkzoo.thechm.org/users/Dan/uploads/SimCityReverseDiagrams.pdf)

**Fuzz-testing SimCity:** CA-scrambled tiles exposed bugs Don fixed — rings of zones, smeared heat diffusion, Godzilla ash trails.
