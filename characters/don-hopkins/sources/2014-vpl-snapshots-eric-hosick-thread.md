# Eric Hosick — VPL Snapshots & "All the Widgets for VPLs" (2014)

**Thread:** Eric Hosick (Interface Vision) · Don Hopkins · Ben Shneiderman · Brad Myers · Scott Kim · Alan Kay · Ben Cerveny

## Don's proposal (Feb 2014)

- **Ken Burns slideshow** through VPL screenshots with tagged POIs + links
- **Infovis table of contents** — cluster by date, influences, application domain
- Built with a **web VPL** (Engi) so viewers can open edit mode
- Style of Brad Myers **"All the Widgets"** (CHI'90) — or James Burke *Connections* (jokingly)
- Metadata as **JSON** — influence graph, domain checkboxes, similarity layout
- Nominate **Ben Cerveny** as James Burke narrator ;)

**Engi** (Don's rave): native JavaScript objects on wires — contrast with Bounce COM/dict extension and Max/MSP bolt-on scripting.

**Don on Bounce/Body Electric** (same thread, Reddit cross-post):

> After using Body Electric / Bounce, I know there is a sweet spot… visually create and edit live programs while they're running.

Credits **Chuck Blanchard**, **Jaron Lanier**, **David Levitt**.
