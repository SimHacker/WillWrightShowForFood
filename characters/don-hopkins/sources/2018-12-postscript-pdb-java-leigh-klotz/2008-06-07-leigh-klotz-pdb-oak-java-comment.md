# Leigh L. Klotz Jr. — blog comment on regex.info (7 June 2008)

**Post:** [Jeffrey Friedl — Source of the famous "Now you have two problems" quote](http://regex.info/blog/2006-09-15/247)  
**Comment date:** 7 June 2008, 3:22am JST (10 years, 7 months before Don's 2018 thank-you email)  
**Author:** Leigh L. Klotz Jr.  
**Context:** Thread about jwz's regex/Perl quotes; jwz said Perl combines *"the power of C with the readability of PostScript"*

---

> OK, I think I've written more PostScript by hand than Jamie, so I assume he thinks I'm not reading this. Back in the old days, I designed a system that used incredible amounts of PostScript. One thing that made it easier for us was a C-like syntax to PS compiler, done by a fellow at the **Turning Institute**. We licensed it and used it heavily, and I extended it a bit to be able to handle uneven stack-armed IF, and added varieties of inheritance. The project was called **PdB** and eventually it folded, and the author left and went to **First Person Software**, where he wrote a very similar language syntax for something called **Oak**, and it compiled to bytecodes instead of PostScript. Oak got renamed **Java**.
>
> So there.
>
> And yes, we did have two problems…

## Notes

- **Turning Institute** in original comment — almost certainly **[Turing Institute](https://en.wikipedia.org/wiki/Turing_Institute)** (Glasgow); Leigh's PdB author aligns with **[Arthur van Hoff](../../../arthur-van-hoff/CHARACTER.yml)** (PdB → First Person → Oak/Java).
- Don extended PdB (uneven stack-armed IF, inheritance varieties) per Leigh and Arthur's room docs.
- Don's 2018 gloss: **PdB = "Pure dead Brilliant"** (Scottish).
