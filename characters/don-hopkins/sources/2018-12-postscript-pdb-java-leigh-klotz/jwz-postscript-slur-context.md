# jwz — "readability of PostScript" (context from Friedl blog)

**Source:** [Jeffrey Friedl — regex.info/blog/2006-09-15/247](http://regex.info/blog/2006-09-15/247)  
**Original:** Jamie Zawinski, comp.emacs.xemacs / alt.religion.emacs thread, 12 Aug 1997

Excerpted for the PostScript-defense thread — what Leigh and Don were pushing back against.

## The PostScript slur (inside a Perl rant)

```
> What's wrong with perl?

It combines all the worst aspects of C and Lisp: a billion different
sublanguages in one monolithic executable.  It combines the power of
C with the readability of PostScript.
```

Same thread — the famous regex quote:

> Some people, when confronted with a problem, think "I know, I'll use regular expressions." Now they have two problems.

## Friedl's framing

jwz *"despised Perl"* and treated Emacs Lisp as religion; embedding Perl in Emacs for regex handling was heresy. Friedl tracked the quote's provenance and reproduced jwz's posts from partial quotes in replies (Google Groups gaps at time of writing).
