# Mark Weiser — pie menu demo tape, alphabetic pies, stylus input (Mar 1991)

Correspondence: Don Hopkins ↔ **Mark Weiser** (Xerox PARC), Mar–Aug 1991.

## Demo tape (Aug 1991)

Mark saw Don's videotape — *"A work of art! Great audio track. I sat mesmerized."* (Mark's wife ran from the room.)

- Mark shows tape to **Bill Buxton** when Buxton is in town; urges Don to contact Buxton.
- Mark's framing advice: bill tapes as **artworks** — gives viewers permission to engage weird personal media (not "computer technology demo").

Don on TNT 2.0: pie menus + tab windows shipping on CD-ROM (**TNT-2.0-4-4-21** "real soon now").

## Alphabetic pie menu trees (6 Mar 1991)

Don → Mark — two-level **6×6** and **6×8** trees for alphabet (+ digits/punctuation):

**6×6 example:**

```
abc  ghi  mno
def  jkl  pqr
     -X-
stu  yz_  ___
vwx  ___  ___
```

- Chunk size **6** fits working memory; `_` slots for numerics / rare glyphs / deeper submenus.
- **Decimal pies**: 10-item clock/phone-dial layout; extra directions for decimal point, edit commands, or range-limited deep digit entry (dim disabled items, don't remove — preserves muscle memory).
- Phone-dial letter grouping (3 letters per wedge) vs 6×6 — Don favors **6×6 for usability**.

## Mark's stylus experiments (5 Mar 1991)

PARC information visualizer group uses gestures (rubout delete) but **not pies**.

Mark hacking **keyboardless input without handwriting recognition**:

- **26-quadrant pie**: each word = connected stroke through letters; ink drops as stylus moves; lift = space. (*"Xerox"* = lopsided X shape.) — **26 is too many**.
- Proposed: **13 inside 13** with state machine — inner letter unless stroke exits to outer ring.

Don had seen **Go PenPoint** tape — impressed; slow on 286 but natural; right to build pen OS from ground up vs grafting pen driver on Windows.

## Urine-testing rumor (5 Mar 1991)

Don thanks Mark for confirming Xerox stopped **summer intern urine tests in research labs** (rest of Xerox still subject). Don offered Diamondback (UMD student paper) coverage.
