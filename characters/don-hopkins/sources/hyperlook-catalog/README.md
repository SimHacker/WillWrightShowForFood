# HyperLook catalog: screen captures, talk slides, brochure cards

Direct screen captures of HyperLook on NeWS (Arthur van Hoff, Turing Institute), mirrored from Don's
HyperLook catalog page, `https://www.donhopkins.com/home/catalog/hyperlook/` (also at
`http://www.art.net/~hopkins/Don/hyperlook/`), fetched 4 Nov 2026. The page itself is saved as
[`catalog-index.html`](catalog-index.html). Captions below are the page's own link text.

Two images from the page live elsewhere in the repo and are not duplicated here:
[`CAM.gif`](../cam6-simulator-wiki/hyperlook-CAM.gif) and
[`HyperLook-SimCity.gif`](../../../will-wright/sources/art-net-simcity-archive/images/HyperLook-SimCity.gif).

## Talk slides

| File | Slide |
|---|---|
| [`TalkRunTime.gif`](TalkRunTime.gif) | "Why We Need a Runtime System": SimCity after user interface vandalism, menus and buttons dragged loose with the editor's selection handles showing. Page caption: "edit HyperLook applications while they're running" |
| [`TalkInterfacing.gif`](TalkInterfacing.gif) | "Interfacing HyperLook to the Real World": hamburger stack, network connection, Unix client process, device driver, robot arm |
| [`TalkGraph.gif`](TalkGraph.gif) | "High Level Interface Between the Client and User Interface": SimCity client C calls (`hl_register`, `hl_send0`) driving the Graphs window |

Don, Hacker News, Feb 9 2020 ([22282598](https://news.ycombinator.com/item?id=22282598)): "However, this
feature did enable 'user interface vandalism', so HyperLook has a non-editable runtime system with the
editors stripped out, that you could ship with apps." The spoken version is in the
[HyperLook SimCity demo transcript](../../../will-wright/sources/art-net-simcity-archive/hyperlook-demo-transcript.md).
