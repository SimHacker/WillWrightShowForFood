## What it is

Don's Monty Python **Cheese Shop** parody of writing a "truely portable" X11 application — display, root, window, colormap, favorite color, visual, ConfigureWindow velocity — each question a trap door. The color model is *"a total flying circus"*; device independence treats everything like *"a MicroVax framebuffer on acid."*

ariels found it while asking why xscreensaver needs helper libraries instead of just `-lX11 -lXext`, and republished it on Everything2 as *"A general rhetorical refutation of the position 'X sucks'"*.
