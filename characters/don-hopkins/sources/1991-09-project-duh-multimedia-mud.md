# Project DUH — multimedia MUD on LambdaMOO (21 Sep 1991)

Don Hopkins → **Kent** (`[email redacted]`), cc self.

## Idea

Given:

- suitable **network name → object server** mapping, and
- an **intelligent front end**,

implement a **multimedia MUD** on top of **LambdaMOO** by storing **handles to typed network objects** as object properties.

Working title: **Project DUH** — *"Distributed Universe Here"*.

Tagline: *"Why have Objects Everywhere when you can have the whole universe at your fingertips?"*
