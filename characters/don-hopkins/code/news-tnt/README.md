# NeWS / TNT sources — cached

Object-oriented NeWS PostScript from Don's Sun era, cached verbatim from
[donhopkins.com/home/archive/NeWS/](https://donhopkins.com/home/archive/NeWS/)
on 2026-08-01.

| File | What |
|---|---|
| [tab.ps](tab.ps) | **Tab Windows for the NeWS toolkit** v3.0.2 (© 1991, unrestricted) — the pie menu tab window manager for TNT: the moveable title tabs that OWM wrapped around X11 and NeWS windows alike. "Pie menus and tab windows are NOT patented or restricted." Mirror: [tab.ps](https://donhopkins.com/home/archive/NeWS/win/tab.ps) |
| [old-xnews-tab.ps](old-xnews-tab.ps) | **NDE Tab Frames** (© 1988–1989, UMD HCIL) — the original tabbed window frames for X11/NeWS, predating the TNT version; the 1988 tabs Don cites on [HN](https://news.ycombinator.com/item?id=18837730) as tabbed windows "long before" browsers. Mirror: [old-xnews-tab.ps](https://donhopkins.com/home/archive/NeWS/old-xnews-tab.ps) |
