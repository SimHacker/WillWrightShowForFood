# Don Hopkins — code

This repo caches copies of code in the directories of the people associated
with it — that is the point. Text sources live here verbatim; only bulky
binaries and media stay on servers.

| Dir | What |
|---|---|
| [piemenu-x10/](piemenu-x10/README.md) | **Cached source** — the 1986–87 UMD X10 origin: theta menu experiments, uwm hacked for pies and scripted in Forthmacs |
| [pieui/](pieui/README.md) | **Cached source** — pie + tab autoload distribution for TNT (`winit.ps` in your `.user.ps` and the desktop grows tabs and pies) |
| [news-tnt/](news-tnt/README.md) | **Cached source** — the tab window lineage 1988→1991 (`tabwin.ps` → NDE → tNt → `tab.ps`), `pie.ps`, `xwm.ps`, `ps.ps`; `owm.ps` itself is in [Josh Siegel's room](../../josh-siegel/sources/owm.ps) |
| [piewm/](piewm/README.md) | **Cached tree** — tvtwm with pie menus for X11, untarred from `piewm.tar.Z` (tarball kept) |
| [tkpie/](tkpie/README.md) | **Cached tree** — Pie Menus for Tk (© 1992), untarred from `tkpie.tar.gz` (tarball kept) |
| [psiber/](psiber/README.md) | **Cached tree** — PSIBER Space Deck: `cyber.ps`, `litecyber.ps`, `empowered.ps` (CHI'90), the distillery, 136 files |
