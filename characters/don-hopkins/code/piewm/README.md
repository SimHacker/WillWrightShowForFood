# piewm — tvtwm with pie menus (cached)

Untarred verbatim from
[art.net/~hopkins/Don/piemenus/piewm.tar.Z](http://www.art.net/~hopkins/Don/piemenus/piewm.tar.Z)
on 2026-08-01 (original tarball kept beside the tree). This is the X11
window manager cited in
[Window Manager Flames](../../sources/i39l-window-manager-flames.md):
tvtwm (twm + virtual scrolling desktop) with Don's pie menu tracking
and layout replacing the linear menus.

From [piewm/README](piewm/README):

> Pie menu tracking (optimized for speed) and layout (optimized for
> screen space) designed and implemented by Don Hopkins.
> These algorithms are not patented or restricted.

| Dir | What |
|---|---|
| [piewm/](piewm/) | The window manager source — `menus.c` is where the pies live; `.o` files ship in the original tarball and are kept for fidelity |
| [xpm/](xpm/) | Bundled XPM pixmap library the build depends on |
| `piewm.tar.Z` | The original compressed tarball, byte-for-byte |
