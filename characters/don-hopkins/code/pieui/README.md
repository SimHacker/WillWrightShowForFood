# pieui — pie menus + tab windows autoload distribution (cached)

Mirrored verbatim from
[donhopkins.com/home/archive/piemenu/pieui/](https://donhopkins.com/home/archive/piemenu/pieui/)
on 2026-08-01. The user-facing distribution of the TNT pie menu and tab
window packages: drop `winit.ps` in your `.user.ps` and your OPEN LOOK
desktop grows tabs and pies — no recompile, no ICCCM negotiation.
This is the "worked together synergistically, take that ICCCM"
packaging from [Don's 2025 comment](https://news.ycombinator.com/item?id=44090952).

| File | What |
|---|---|
| [winit.ps](winit.ps) | Autoload shim — loads pies and tabs from `.user.ps` at server start |
| [pie.ps](pie.ps) | Pie Menus for the NeWS toolkit (same lineage as [news-tnt/pie.ps](../news-tnt/pie.ps)) |
| [tab.ps](tab.ps) | Tab Windows for TNT (same lineage as [news-tnt/tab.ps](../news-tnt/tab.ps)) |
