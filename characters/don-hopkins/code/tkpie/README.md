# tkpie — pie menus for Tcl/Tk (cached)

Untarred verbatim from
[art.net/~hopkins/Don/piemenus/tkpie.tar.gz](http://www.art.net/~hopkins/Don/piemenus/tkpie.tar.gz)
on 2026-08-01 (gzip timestamp: 19 Sep 1993; original tarball kept).
Pie menus as a native Tk widget — the same era as the TkWM discussion
in [Window Manager Flames](../../sources/i39l-window-manager-flames.md),
where an extensible Tcl/Tk window manager was the proposed way to get
OWM-style flexibility on X11.

From the `tkPieMenu.c` header: "Pie Menus for Tk. Copyright (C) 1992
by Don Hopkins… developed over time by Don Hopkins with the support of
the University of Maryland, UniPress Software, Sun Microsystems, DUX
Software, the Turing Institute, and Carnegie Mellon University. Pie
menus are NOT patented or restricted."
