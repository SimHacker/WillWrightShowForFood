# Emacs NeWS drivers (cached)

Cached verbatim from donhopkins.com on 2026-08-01. The Emacs side of
the story: UniPress Emacs 2.20 was the first commercial product with
multiple tabbed windows (via [tabwin.ps](../news-tnt/tabwin.ps)), and
GNU Emacs 18 got a TNT display driver so it could live inside the
OPEN LOOK desktop with pies and tabs.

| File | What |
|---|---|
| [emacs.ps](emacs.ps) | UniPress Emacs NeWS/PreScript display machinery (© 1987–88 UniPress Software) — [source](https://donhopkins.com/home/archive/emacs/emacs.ps) |
| [tnt.ps](tnt.ps) | GNU Emacs 18 TNT interface (Chris Maio, modified Don Hopkins, last edit May 30 1991) — [source](https://donhopkins.com/home/code/emacs18/src/tnt.ps) |

The FORTH-uwm tree in [piemenu-x10/uwm/](../piemenu-x10/uwm/) has the
matching `call-emacs.f` — the window manager calling Emacs, X10 era.
