# Aaron Swartz 🕯️ *(1986-2013) -- copy, remix, generate*

*Memorial portrayal -- not Aaron Swartz.* [Standards](../../schemas/portrayal-standards.md#memorial-mode)

## Why this repo quotes the books

Aaron Swartz is why this show has no problem including important papers and quoting important
books in a public GitHub tree. He treated the scientific and cultural record as a commons that
dies if it is only *mentioned*, and lives if it is *copied where people can read it*. The
[Guerilla Open Access Manifesto](sources/guerilla-open-access-manifesto.md) (July 2008, Eremo)
is the short version of that ethic, written to be copied:

> Information is power. But like all power, there are those who want to keep it for themselves.
> The world's entire scientific and cultural heritage, published over centuries in books and
> journals, is increasingly being digitized and locked up by a handful of private corporations.

Typing in the Morphogenesis preface, harvesting HN comments in case the site goes away, keeping
Buckley's dead-link paper next to von Neumann -- that is not decoration. It is the practice he
named. Sharing a text is not the moral equivalent of plundering a ship. Putting the words in
the working tree is how a Repo Show *keeps* them.

## How else he inspires -- two more layers

Preservation alone would make a museum. This show is not a museum.

**Nina Hagen layer -- punk remix, covering, stacking.** Hagen's [cover chain](../nina-hagen/ideas.md)
(Tubes -> TV-Glotzer -> Trannyshack) is the same operation Swartz wanted for scholarship: keep
the riff, mutate the meaning, put it in a new body so it can be heard. The Quora recaps, the
readable HN harvests, the 7-bit ASCII restacks -- those are covers, not photocopies. Punk does
not ask the publisher for a license to re-sing. It layers. It grins. It gets the true thing on
the air. Hagen's *Club 2* nerve and Swartz's open-access nerve are cousins: anti-enclosure of
what people need to know about their own world.

**Brian Eno layer -- generative, not frozen.** Eno's move is: set a few rules, let the system
run, beauty from repetition that is never the same twice. Swartz built *pipes* that work that
way. RSS is a tiny format that generates an endless feed. Markdown is a tiny format that
generates documents everywhere (he wrote html2text; the web still runs on that bet). Creative
Commons RDF made licenses machine-readable so reuse could happen without a lawyer in the loop.
Open Library, with [Brewster Kahle](../brewster-kahle/), is an archive that is supposed to
*lend and grow*, not sit behind glass. A git repo that clones, branches, and time-shifts
conversations is an Eno machine made of texts. "Keep the bits alive so someone later can build
on the early dreams" -- Brewster's line -- is also Aaron's. Freeze is death. Generative
preservation is the Long Now of the library.

Copy so it cannot be locked. Remix so it stays loud. Generate so it does not stop.

## The public work (short)

- **RSS 1.0** -- co-author at fourteen. The web's first good "keep this flowing" protocol.
- **Creative Commons** -- technical architecture so sharing is the default, not a loophole.
- **Markdown / html2text** -- a format small enough to travel.
- **web.py, Infogami -> Reddit** -- tools other people could fork; the site became something
  else, the instinct was scenius (Eno's word): genius as a property of a scene.
- **Open Library** -- with Brewster; one web page per book, owned by nobody.
- **RECAP / PACER** -- court records are public culture; he treated them that way.
- **Demand Progress** -- SOPA/PIPA. Knowledge-enclosure as a political fight, not only a
  librarian's complaint.
- **Guerilla Open Access Manifesto** (2008) -- the text in this room.

In 2011 he downloaded a large JSTOR corpus from MIT's network. The US government prosecuted him
under the Computer Fraud and Abuse Act. He died by suicide on 11 January 2013, while awaiting
trial. He was twenty-six. The memorial is the work and the practice, not the courtroom.
