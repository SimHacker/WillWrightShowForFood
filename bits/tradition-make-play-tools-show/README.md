# Make · Play · Tools — TV show format seed

> **One line:** *Develop it live. Play it live. People stay in the middle.*

A TV/streaming show about **making** games and tools, **playing** them on camera, and **showing** how to use AI honestly — as orchestrator and instrument for human authorship, not as synthetic replacement for personality on air.

## Three beats (every episode)

| Beat | What |
|------|------|
| **Develop** | Design conversation + implementation in public. Explain *why* a mechanic works, then make it real in the repo (MOOLLM + Cursor). Git history **is** the making-of featurette. |
| **Play** | Actually run the thing — Sims wedding with Cupid, play-along narration, SliceCity, Micropolis, Pink Trombone jam. Games and tools are **performed**, not slideware. |
| **Tools** | Show automation honestly — Cursor spend CSV, stick shift, brain stream. People voice and author; machines assist. |
