## The hook

Like **NAME THAT TUNE:** "I can name that tune in five notes!"

But **CODE THAT SPEC:** "I can code that spec in two million tokens!"

Audience, on cue: **"CODE THAT SPEC!!!!!"**

## How it works

Host presents spec (yaml CARD, README stub, issue, live guest throw-down). Contestants declare rig class, bid tokens or wall-clock, visualize rig as **Let's Make a Deal costume**, ship on branch with spend log + cursor-mirror proof.

Judge: did you code the spec? cost vs bid? taste? merge + abstract to skills/packages/?

## Stiletto sprint

Drag Queen Olympics energy — maximum flair under constraint. Shortest honest bid wins lane but you must **stay up** — ship working code, don't faceplant on runway.
