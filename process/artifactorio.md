## The hook

**Factorio, but belts carry skills and assemblers build assemblers.** The game about skill-skills — you automate building the builders. Papert: "You can't think about thinking without thinking about thinking about something."

## Win / lose

**Win:** self-sustaining factory of builders that stops on satisfy and stamps provenance.

**Lose:** Autofac runaway (unwanted output floods belts) or coprophagia (assemblers fed only own output → model collapse).

Resources: tokens consumed on read, generated on write. Belts: git timeline.
