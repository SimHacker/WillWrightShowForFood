## The hook

Pinned GitHub issues as the show's **switchboard** — one topic per issue, stable URL, accumulating like an answering machine tape. Every participation type gets a well-lit front door; doors arranged in a **ladder**: easy leading to hard, each rung demonstrated on camera before anyone is asked to climb.

## Funnel types

| Type | Scope |
|------|-------|
| **Reusable** | One funnel, many shows (roars issue, answering machine) |
| **Special purpose** | One funnel for one show/series |
| **General** | Suggestion box + viewer call-in catch-all |

## Participation ladder

1. **SAY HI** — reply to onboarding issue
2. **LEAVE A MESSAGE** — answering machine issue
3. **CONTRIBUTE A ROAR** — audio/video + mood tag
4. **DRAW A MONSTER** — sprite sets + rights grant
5. **MAKE A TicketPR** — git tutorial tier
6. **CREATE AUDIENCE CHARACTER** — questions, personality, costume
7. **GO DEEPER** — code, content, skills

Progressive master class **by example**. GitHub account = passport into open source community.

## Inverted Hollywood Principle

"Don't call us, we'll call you" inverted: **DO call us, and we'll call you BACK.** CS dependency-injection in-joke that's literally true of the format.

## Roars of support

Roars are **roars of support** — monster's voice and audience's. Drive FOR something, never against anyone by name. Hate Man spirit: roar first, talk after.

## Artist ask

Advanced ask for graphical artists — draw sprite sets for your own monsters. Anti-AI-slop human work centered, not disclaimed.

## Show hooks

- **Onboarding issue live:** Don makes Will a GitHub account on camera.
- **Standing roars issue:** Pin + demonstrate upload in one minute.
