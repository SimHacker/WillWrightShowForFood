# Couple shows vs solo shows

[Guest participation ladder](guest-participation-ladder.md) · [MOOLLM stage](moollm-stage.md) · [Character INDEX](../characters/INDEX.yml)

---

## The hook

One show per character (or pair). Shows have **episodes** — guests return as themselves. Bread-and-butter: casual async one-on-ones woven in post. Readings show + rare synchronized specials are separate tiers.

Each person gets exactly one directory: `characters/<first-last>/` — hyphenated slug, no role suffixes. Roles live in CHARACTER.yml, not slugs.

## Show tiers

| Tier | What |
|------|------|
| **Ongoing one-on-one** | Default — late-night-style interviews, one guest, recorded when it suits them, woven async |
| **MOOLLM readings** | Long-form script readings — [repo-shows/moollm-readings/](../repo-shows/moollm-readings/) — performance + pedagogy |
| **Special events** | Twitch, group table read, audience play-along — plan ahead; not weekly default |

## Natural couples

Married or long-running creative partners who ship shared work together — interview **as a pair** for the shared story.

| Pair | Show |
|------|------|
| Heather + Steve Alvey | [heather-and-steve-alvey](../repo-shows/heather-and-steve-alvey/) |
| Amy Jo Kim + Scott Kim | [amy-jo-and-scott-kim](../repo-shows/amy-jo-and-scott-kim/) |

Pair show is default for shared career chapters. Two one-on-ones at each person's best time, woven in post, is fine.

## Memorial shows

Possible — no hard-and-fast rules ahead of time. **Easiest path for friends of the deceased:** phone tribute clips — one person, one memory, one story. No studio, no schedule coordination.

Do not speak AS the deceased or invent quotes — discuss ABOUT them only.

## Async production

Minimally intrusive interviews, **time-shifted and woven together** — can be the whole style. Repo is staging layer: research bundles, guest walks bundle on camera, face puppet clips, memory palace talking selfies, audience opens same paths in Cursor.

**Will's guest prototype:** optimize every process for Will's time first — async one-on-one, topic-less, no homework, episodes not one-shot.

## Show hooks

- **Naming beat:** "Heather Alvey, not Heather (SimFreaks)" — roles in yaml, not slugs.
- **Episode not sequel:** Same guest returns on their own show — normal, not gimmick.
- **Memorial phone clip:** Friend in a park, one story — async weave.
