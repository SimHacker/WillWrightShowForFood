# Trail — visual_programming_patch_cord

> *Boxes, lines, and patch-cords — from Hookup to Snap!*

[22788773](https://news.ycombinator.com/item?id=22788773), Image/ine [33668198](https://news.ycombinator.com/item?id=33668198), Yahoo Pipes successors [40842599](https://news.ycombinator.com/item?id=40842599)).

## Patch-cord genealogy (compressed)

```
Hookup (David Levitt, MIT)
  → Interactor → Isadora (Mark Coniglio)
  → Max/MSP (Miller Puckette lineage)

Body Electric (VPL, Chuck Blanchard + Jaron Lanier)
  → Bounce (David + Don @ Levity, MMP/Shockwave lineage)

Image/ine (Steina + Tom Demeyer @ STEIM)
  → Isadora absorbs realtime video features
```
