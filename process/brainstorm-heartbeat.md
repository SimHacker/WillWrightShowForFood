# Brainstorm heartbeat — why guests say yes

Machine girder: [`brainstorm-heartbeat.yml`](brainstorm-heartbeat.yml)

## The heartbeat

Guests **brainstorm**. They talk about how they'd go about a design, what the
alternatives and tradeoffs are, what the elegant solution looks like — and we
throw those designs into the public repo for other people to play with.

That is the heart of the Repo Show. That is why invitations are easy to accept:

**We are not asking anyone to write code.**

Implementation is optional *homefun* ([homefun-grading.yml](homefun-grading.yml)) —
for the guest later, for the audience, for Don, for whoever gets excited. Credit
stays with the originators. The talk is the gift.

## What we ask

| Ask | Not ask |
|-----|---------|
| Talk and brainstorm | Implement before air |
| Name tradeoffs and elegant paths | Finish a prototype |
| Correct our notes | Homework |
| Point at prior art / dead ends | Synchronized coding sessions |

Inherits [Will’s guest prototype](../characters/will-wright/guest-prototype.yml) —
respect time; repo does the staging; episodes accumulate.

## Invitation line (reuse)

> **The ask is conversation, not code.** Brainstorm designs, tradeoffs, elegant
> paths — we write them down in the repo for others to play with. Zero homework;
> as much *homefun* as you like later.
