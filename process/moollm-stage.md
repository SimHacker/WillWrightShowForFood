## The hook

MOOLLM is the ideal environment for Repo Show discussions — navigable rooms, ongoing narrative, harvestable skills. The show is performed **inside** the world, not documented beside it. WWSFF is the public bud; the [adventure-4 pub](https://github.com/SimHacker/moollm/tree/main/examples/adventure-4/pub/) is third place — neither home nor work.

## The pie table

The **round pie-menu table** — octagonal, all voices equidistant from center. People pop in, ring to speak, add to an **ongoing** discussion without a scheduled roundtable.

Also: conference rooms (topic-focused shows), coffee shops (smaller circles), theaters (readings, performances, audience play-along). Each room can host an ongoing show — not one-and-done events.

## Pub as show

The **pub is itself a show** — it publishes **episodes** when somebody wanders in and continues the conversation. Each episode is a **chat narrative session log** appended to the ongoing thread.

Canon examples:

- [Don Hopkins marathon session](https://github.com/SimHacker/moollm/blob/main/examples/adventure-4/characters/real-people/don-hopkins/sessions/marathon-session.md)
- [World tour — Leela Manufacturing](https://github.com/SimHacker/moollm/blob/main/examples/adventure-4/characters/real-people/don-hopkins/sessions/world-tour-leela.md)

Sessions need not stay at the pie table — pub → Lane Neverending → skill rooms → rooftop. World tour = curriculum + entertainment.

## Repo Show bridge

| Layer | Role |
|-------|------|
| WWSFF | Public Repo Show — shotgun-blast ensemble, guest prototype |
| MOOLLM | Third place + session logs + room graph — where discussions happen |
| Together | Guest async video walks the WWSFF bundle; pub session logs capture pop-in continuations; audience jumps between git paths and pub narrative in Cursor time-shifted |

**Memory palace tour:** face puppets at each palace stop — git room + artifact + one K-line; tour on stream or async clips per room.

## Session → skill harvest

Every substantial **session log** should be **harvested into a MOOLLM skill** — protocol distilled from what happened, links preserved, CARD + SKILL.md body.

**Criterion Collection overlay:** humans who were there record a second pass — voice-over or async video — talking **over** the session log. Backstory, why they said what they said, what actually happened.

Layers: session log → commentary track → skill (GLANCE → CARD → SKILL → README). Harvest via [cauldron](https://github.com/SimHacker/moollm/tree/main/skills/cauldron).

## Ongoing shows

Conference rooms, coffee shops, theaters, and the pub each run **ongoing shows** — new session logs are episodes, not reboots. Will Wright's WWSFF show and MOOLLM pub threads can intertwingled.

## Show hooks

- **Pub pop-in:** MOOLLM session log appended live during a Repo Show segment.
- **World tour clip:** One stop = one K-line + one artifact + one face puppet.
- **Commentary track:** Harvest a marathon session into a skill with director's commentary.
