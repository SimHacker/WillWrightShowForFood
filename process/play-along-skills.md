## The hook

Every Repo Show ships AI Skills you plug into Cursor (or another AI tool) to **Play Along** — before, during, and after — by participating in the GitHub repo the way software teams do: clone, branch, commit, push, PR, review, merge, issues, discussions.

**MOOLLM is the core.** The Repo Show is a **distribution hook** for MOOLLM — Anthropic-format Agent Skills are portable delivery wrappers; the substance is MOOLLM.

## Embrace, Extend, Share

Ethical inversion of Microsoft's Embrace, Extend, **Extinguish**. We **embrace** open standards (git, GitHub, Anthropic skills, the web), **extend** them with MOOLLM, and **share** the result openly. No lock-in, no extinguish.

## Preloaded runtime

Like HyperLook apps on the HyperLook runtime — ship a **safe, focused, preloaded MOOLLM subset** tuned for THIS show: just the skills + context a participant needs. MOO generates these optimized per-repo runtimes.

The subset is a doorway **into** full MOOLLM — start scoped, expand when you want the whole microworld.

## How to play along

| Phase | Actions |
|-------|---------|
| **Setup** | Clone repo; plug show's Skills into Cursor |
| **Before** | Branch + author TicketPR character; open issues/discussions |
| **During** | Commit + push in real time; merged character participates live |
| **After** | Homefun on a branch; async via issues/PR threads |

**Git verbs:** clone, branch, stage, commit, push, pull-request, review, merge, issue, discussion.

Reviewed + merged PRs land on `main` — the canonical show timeline. Master ⇒ PR, master branch ⇒ main.

## Why GitHub

Battle-tested collaboration: forks, branches, review, merge, CI, issues, discussions, permissions, history. PR review + maintainer merge gives real curation and moderation for free. Everything inspectable, forkable, permanent.

## Show hooks

- **Live commit:** Audience pushes during stream; GitHub activity feed surfaces in chat.
- **Skill install demo:** Preloaded runtime boot on camera — scoped MOOLLM in 60 seconds.
- **Homefun harvest:** Show idea → branch → PR → cauldron melt → skill lift.
