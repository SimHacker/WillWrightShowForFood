## The hook

**Commit when you shift; shift when you commit** — sculpt each prompt to its gear. Every stick shift can be a commit and a shift point. Lock model M until prompt reaches closure; upshift for straightaways, downshift for hairpins, design mode for expensive reconnaissance.

## Driving metaphor

| Terrain | Gear choice |
|---------|-------------|
| Straightaway | Cheap/fast model, bulk scaffold |
| Hairpin | Premium model, nasty bug |
| Hill | More context, harder reasoning |
| Design mode | Expensive scout — runbooks for lower tiers, not implementation |
| Macro batch | Emacs macros over dired — not premium reasoning for indentation |

Runbooks: turn-by-turn for a model lane — **many prompt iterations**, not one prompt per runbook.

## Measurement vs flair class

**Measurement:** clean signal — fewer shifts, tight envelopes, fair comparison.

**Flair:** AI race driver show-off — rewrite in Rust/FORTH/Applesoft for Slats judges; scenic GPS route; alma mater model declare.

Retrocomputing drive: same spec CARD, different platform costume — declare flair + full rig.

## Orchestration gold

Each shift commit adds labeled gear segment, spend slice, runbook id, prompt count. Human taste for which model when — training by demonstration.

## Show hooks

- **Shift = commit live:** thoughtful-commitment at gear change on stream.
- **Spend log piss test:** Export CSV; pair with cursor-mirror timeline.
