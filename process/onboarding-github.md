# GitHub onboarding — for guests

*How to participate with (or without) a GitHub account. Linked from the
[portrayal standards](../schemas/portrayal-standards.md#onboarding) so invitations never have to
explain any of this.*

**You never need any of this to be a guest.** Email Don plain text, attachments, or URLs and he
commits them for you with attribution. This page is for guests who'd like to touch the repo
themselves.

## Zero-account participation

- **Browse everything** — the repo reads like a website; no account, no login:
  [https://github.com/SimHacker/WillWrightShowForFood](https://github.com/SimHacker/WillWrightShowForFood)
- **Email Don** — corrections, stories, files, links. He places vetted material in your room and
  credits you. This is the default path and it is a first-class one.

## With a free GitHub account

Sign up at [https://github.com/signup](https://github.com/signup) — free, any handle, two minutes.
That unlocks, in increasing order of involvement:

1. **Open an issue** — a public note to the repo: a correction, a question, a story. Go to the
   [Issues tab](https://github.com/SimHacker/WillWrightShowForFood/issues), click *New issue*, type, submit.
2. **Comment** on existing issues and pull requests — join a conversation already in progress.
3. **Edit a file in the browser** — open any file in your room, click the **pencil icon**, type
   your changes, and GitHub walks you through proposing them (it quietly makes a fork and a pull
   request for you — you don't need to know what those words mean). Don reviews and merges.
4. **Upload files in the browser** — *Add file → Upload files* works for photos, PDFs, and clips
   without any tools.

## Direct access — your room, your keys

If you'd rather skip the propose-and-review dance: **ask Don to add you as a collaborator** and
you can edit your own directory directly. Your room is yours — remove, edit, replace, or add to
anything in it. [Subject rights](../schemas/portrayal-standards.md#subject-rights) apply either
way; access just makes them self-service.

## One quiet-mode caution 🤫

While the repo is in [stealth mode](../schemas/portrayal-standards.md#stealth-mode), please
**don't star, share, or link it publicly** yet — starring and forking show up in your public
GitHub activity feed. Watch it instead (*Watch → All activity*), which is private to you.
